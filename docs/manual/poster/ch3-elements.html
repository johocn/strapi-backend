第三章元素配置

3.1 元素基础属性

每个海报元素都有一组基础属性，用于定义元素的标识、类型和排序。这些属性适用于所有元素类型。

elementType enumeration / required / default: text 必填
设计初衷
定义元素的渲染类型，决定前端使用何种方式绘制该元素。不同类型对应不同的样式配置字段。
枚举值
text — 文本元素，渲染文字内容
image — 图片元素，渲染指定 URL 的图片
qrcode — 二维码元素，根据内容生成二维码图片
shape — 形状元素，渲染矩形/圆形/线条等几何图形
background — 背景元素，作为画布背景之上的额外背景层
标准填写规范
根据元素用途选择对应类型。标题、描述、价格等文字内容使用 text；封面图、产品图使用 image；分享二维码使用 qrcode；装饰性图形使用 shape；遮罩层、渐变层使用 background。
elementKey string / required 必填
设计初衷
元素的唯一标识符，用于在模板内区分不同元素。前端可通过此 key 查找特定元素。
作用原理
存储为字符串。管理后台编辑器中添加新元素时自动生成 element_{timestamp} 格式的 key，建议手动修改为有语义的值。
标准填写规范
使用 snake_case 命名，如 title、cover_image、qr_code、price_label、footer_text。同一模板内不应重复。
错误后果
key 重复不会导致数据库错误，但会导致前端通过 key 查找元素时无法区分。使用无语义的 key（如 element_123）增加维护难度。
elementName string 选填
设计初衷
元素的显示名称，用于管理后台元素列表中展示，方便运营人员识别元素用途。
标准填写规范
使用中文名称，如"课程标题""封面图""分享二维码""底部提示"。与 elementKey 对应但使用人类可读的名称。
sortOrder integer / default: 0 选填
设计初衷
控制元素在返回数组中的排列顺序。值越小越靠前。
作用原理
服务层在返回元素列表时按 sortOrder 升序排序（内存排序）。建议从 1 开始递增。
标准填写规范
从背景到前景依次设置：background=1, image=2, shape=3, text=4, qrcode=5。与 zIndex 保持逻辑一致。

3.2 元素类型详解

text (文本元素)

文本元素用于渲染文字内容。支持字体大小、颜色、粗细、对齐方式、行高、字间距等样式配置。文本内容可以来自变量绑定或固定 content。

字段类型默认值说明
fontSizeinteger14字号（px）
fontColorstring#333333字体颜色（HEX）
fontWeightenumnormal字重：normal / bold
fontFamilystringsans-serif字体族名称
textAlignenumleft对齐：left / center / right
lineHeightdecimal1.5行高倍数
letterSpacinginteger0字间距（px）
字体使用建议

使用 fontFamily 指定字体时，需确保目标用户设备上已安装该字体。常见安全字体：sans-serif（默认无衬线）、Microsoft YaHei（微软雅黑）、PingFang SC（苹方）。如果使用自定义网络字体，前端需要在 Canvas 渲染前预加载字体文件。

image (图片元素)

图片元素用于渲染指定 URL 的图片。支持图片适配模式控制。图片 URL 可以来自变量绑定或固定 content。

字段类型默认值说明
imageFitenumcover图片适配模式
borderRadiusinteger0圆角（px）
borderWidthinteger0边框宽度（px）
borderColorstring#000000边框颜色
elementBgColorstring-元素背景色（图片加载前的占位色）

imageFit 枚举值说明：

值行为等效 CSS
cover等比缩放填满元素区域，超出部分裁剪background-size: cover
contain等比缩放完整显示在元素内，不足部分留白background-size: contain
stretch拉伸填满元素区域，可能变形background-size: 100% 100%
tile平铺重复填满元素区域background-size: auto

qrcode (二维码元素)

二维码元素根据内容生成二维码图片。支持两种内容模式：direct（直接使用传入内容生成二维码）和 url_with_invite（将基础 URL 与邀请码拼接后生成二维码）。二维码的详细配置请参见第四章。

字段类型默认值说明
qrContentModeenumdirect内容模式：direct / url_with_invite
qrBaseUrlstring-基础 URL（url_with_invite 模式使用）
qrInviteParamstringinviteCode邀请码参数名
qrInviteSeparatorstring?参数分隔符
qrFallbackModeenumbase_url_only降级模式
qrErrorLevelenumM容错级别：L / M / Q / H
qrSizeinteger120二维码尺寸（px）
qrColorstring#000000二维码颜色
qrBgColorstring#FFFFFF二维码背景色

shape (形状元素)

形状元素用于渲染几何图形，作为海报的装饰性元素。支持三种形状类型。

字段类型默认值说明
shapeTypeenumrect形状类型
elementBgColorstring-形状填充色
borderRadiusinteger0圆角（rect 模式下生效）
borderWidthinteger0边框宽度
borderColorstring#000000边框颜色

shapeType 枚举值说明：

值形状说明
rect矩形填充元素区域的矩形，支持 borderRadius 圆角
circle圆形在元素区域内绘制圆形（直径 = min(width, height)）
line线条在元素区域内绘制水平线条

background (背景元素)

背景元素用于在画布背景之上、其他元素之下添加额外的背景层。典型用途包括半透明遮罩、渐变层、装饰性背景图案。背景元素通常设置较低的 zIndex（如 0 或 1），覆盖整个画布区域。

background 元素与画布背景的区别

画布背景（backgroundColor/backgroundImage）是模板级配置，始终位于最底层，不可定位。background 元素是元素级配置，可以指定位置、尺寸、透明度，适合创建局部遮罩或渐变效果。例如：在封面图上叠加一个半透明黑色遮罩条，使叠加的文字更清晰——这时使用 background 元素设置 elementBgColor: rgba(0,0,0,0.5)，定位到文字所在区域。

3.3 元素定位与尺寸

所有元素都通过以下字段进行定位和尺寸控制。坐标原点 (0,0) 位于画布左上角。

x / y integer / default: 0 必填
设计初衷
定义元素左上角在画布坐标系中的位置。x 为水平坐标，y 为垂直坐标。
作用原理
前端 Canvas 渲染时，使用 ctx.translate(x, y) 或 drawImage(img, x, y, ...) 定位元素。管理后台预览按缩放比例显示位置。
标准填写规范
x 范围 0 到 canvasWidth-width，y 范围 0 到 canvasHeight-height。居中放置的元素 x = (canvasWidth - width) / 2。如画布宽 600，元素宽 500，居中 x = 50。
错误后果
x 或 y 为负值会导致元素部分超出画布左/上边缘被裁剪；x + width 超过 canvasWidth 会导致元素右侧被裁剪。
width / height integer / default: 100 必填
设计初衷
定义元素的宽度和高度（像素）。元素内容在此外围矩形内渲染。
作用原理
前端 Canvas 在 (x, y, width, height) 矩形区域内绘制元素。文本元素在此区域内换行；图片元素在此区域内按 imageFit 适配；二维码在 min(width, height) 范围内绘制。
标准填写规范
宽度通常与画布宽度配合使用。如画布宽 600，左右各留 50px 边距，元素宽 500。高度根据内容类型调整：标题 50px，描述 60px，封面图 300px，二维码 120px。
错误后果
宽度过小导致文字被截断；高度不足导致多行文字被裁剪；二维码的 width 和 height 不一致会导致渲染变形。
zIndex integer / default: 0 选填
设计初衷
控制元素的视觉层叠顺序。数值越大，元素越靠上层。
作用原理
前端 Canvas 按元素数组的顺序绘制（后绘制的覆盖先绘制的），同时参考 zIndex 进行排序。管理后台预览使用 CSS z-index 属性。
标准填写规范
建议分层设置：background=0, image=5, shape=5, text=10, qrcode=10。确保文字和二维码始终在图片和形状之上。同一层级内的元素按 sortOrder 排序。
错误后果
文字元素的 zIndex 低于图片元素时，文字会被图片遮挡不可见；所有元素 zIndex 相同时，渲染顺序依赖 sortOrder，可能导致层叠不符合预期。

3.4 元素变换属性

rotation integer / default: 0 选填
设计初衷
控制元素的旋转角度（度）。正值顺时针旋转，负值逆时针旋转。
作用原理
前端使用 ctx.rotate(rotation * Math.PI / 180) 旋转元素。旋转中心为元素的左上角 (x, y)。管理后台预览使用 CSS transform: rotate()。
标准填写规范
范围 -360 到 360。常用值：0（不旋转）、90（竖排文字）、-45（斜角装饰）、180（倒置）。大部分元素保持 0。
错误后果
旋转后元素的实际占位区域会超出原始 width/height 矩形，可能与其他元素重叠；旋转角度不是 90 的倍数时，元素边缘可能出现锯齿。
opacity decimal / default: 1 选填
设计初衷
控制元素的透明度。0 完全透明，1 完全不透明。
作用原理
前端使用 ctx.globalAlpha = opacity 设置全局透明度。管理后台预览使用 CSS opacity 属性。
标准填写规范
范围 0 到 1，步长 0.1。常用值：1（不透明，默认）、0.5（半透明遮罩）、0.8（轻微透明）。装饰性遮罩层使用 0.3-0.7。
错误后果
opacity 为 0 时元素完全不可见但仍占据渲染资源；过高值（如 0.95）与 1 几乎无视觉差异但增加渲染计算。

3.5 元素样式配置

文字样式

文字样式字段仅在 elementType: text 时生效。这些字段控制文本的视觉表现。

字段类型默认值说明
fontSizeinteger14字号（px），标题建议 24-32，正文 14-16，注释 12
fontColorstring#333333字体颜色（HEX 格式）
fontWeightenumnormal字重：normal（常规）/ bold（粗体）
fontFamilystringsans-serif字体族，如 "Microsoft YaHei", "PingFang SC"
textAlignenumleft对齐方式：left / center / right
lineHeightdecimal1.5行高倍数，1.5 表示 1.5 倍字号
letterSpacinginteger0字间距（px），正值增加间距

边框与圆角

边框和圆角字段适用于所有元素类型，但最常用于 image 和 shape 元素。

字段类型默认值说明
borderRadiusinteger0圆角半径（px），图片圆角常用 8-12
borderWidthinteger0边框宽度（px），0 表示无边框
borderColorstring#000000边框颜色（HEX 格式）
elementBgColorstring-元素背景色，作为图片加载前的占位或形状的填充色

3.6 元素内容配置

元素的内容来源由 isVariable 字段决定。当 isVariable 为 true 时，元素内容来自变量；为 false 时，使用固定 content 字段。

字段类型默认值说明
isVariablebooleanfalse是否为变量驱动
variableNamestring-绑定的变量名（isVariable=true 时生效）
defaultValuetext-变量缺失时的回退值
contenttext-固定内容（isVariable=false 时生效）

内容解析规则

解析优先级

当 isVariable=true 且 variableName 已设置时：
1. 若变量名是 invite_code 且未传入该变量 → 使用 defaultValue
2. 若变量已传入 → 使用变量值
3. 若变量未传入且非 invite_code → 使用 defaultValue（为空则使用空字符串）

当 isVariable=false 时 → 直接使用 content 字段值

3.7 管理后台元素编辑器

管理后台的模板编辑器提供了基于表单的元素配置界面。编辑器分为三个区域：

区域位置功能
模板属性 + 画布预览左侧（占 1/3 宽度）模板基础信息表单 + 实时画布预览
元素列表右侧上方（占 2/3 宽度）元素表格列表，支持选择、添加、删除
元素编辑表单右侧下方当前选中元素的详细属性编辑

编辑器使用流程

  1. 选择元素 — 在元素列表中点击某一行，该元素被选中并高亮显示，同时画布预览中对应元素以蓝色边框标识
  2. 编辑属性 — 在元素编辑表单中修改属性值，表单使用折叠面板分组：基础信息、位置与尺寸、文字样式（仅 text 类型）、边框与背景、二维码设置（仅 qrcode 类型）、形状设置（仅 shape 类型）
  3. 实时预览 — 表单值变更时（onValuesChange），画布预览实时更新元素位置和样式
  4. 添加元素 — 点击"添加元素"按钮，创建一个默认配置的空元素，自动选中新元素
  5. 删除元素 — 点击元素行的删除按钮，确认后移除该元素
  6. 保存全部 — 点击"保存全部元素"按钮，通过批量保存 API 一次性写入所有元素
批量保存的覆盖行为

批量保存 API（PUT /api/zhao-studio/v1/admin/poster-templates/:id/elements）采用先删后建策略：先删除该模板下所有现有元素，再根据传入的元素数组逐一创建新元素。这意味着每次保存都会重置元素 ID。如果前端缓存了元素 ID，需要在保存后重新获取。

画布预览缩放

预览区域根据模板画布尺寸自动缩放，确保预览宽度不超过 400px，高度不超过 500px。缩放比例计算公式：

previewScale = min(400 / canvasWidth, 500 / canvasHeight, 1)

例如画布尺寸 600x1000，缩放比例 = min(400/600, 500/1000, 1) = min(0.667, 0.5, 1) = 0.5，预览区域为 300x500。所有元素的坐标和尺寸在预览中按此比例缩放显示。
