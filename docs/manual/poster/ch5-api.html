第五章前端 API 集成

5.1 API 总览

海报模板功能提供两类 API：公开 API（无需认证，供前端 C 端调用）和管理端 API（需认证和权限，供管理后台调用）。所有 API 的基础路径为 /api/zhao-studio/v1。

类别路径前缀认证权限策略用途
公开 API/api/zhao-studio/v1/posters无需认证 (auth: false)无前端获取模板配置、提交变量渲染
管理端 API/api/zhao-studio/v1/admin/poster-templates需认证is-authenticated + has-permission + has-channel-scope + has-tenant-access模板 CRUD、元素 CRUD、批量保存、克隆

5.2 公开 API

获取模板配置

GET /api/zhao-studio/v1/posters/templates/:code 公开 API 无需认证
用途
根据模板编码获取完整的模板配置（包含元素列表）。前端在渲染海报前调用此接口获取布局配置。
路径参数
code — 模板唯一编码，如 course_share_default
查询条件
系统自动附加 isActive: true 过滤条件，仅返回已启用的模板。

前端集成建议

前端有两种集成方式：
方式一（两步式）：先调用 GET /posters/templates/:code 获取原始模板配置（用于展示模板预览），再调用 POST /posters/render 获取已解析配置进行渲染。
方式二（一步式）：直接调用 POST /posters/render，一步获取已解析的元素配置，直接渲染。适用于不需要展示原始模板预览的场景。

5.4 批量保存元素 API

PUT /admin/poster-templates/:id/elements 管理端 API 需认证
用途
一次性保存模板的所有元素。采用先删后建策略：先删除该模板下所有现有元素，再根据传入的元素数组逐一创建。
请求体
{
  "elements": [
    {
      "elementType": "text",
      "elementKey": "title",
      "elementName": "课程标题",
      "isVariable": true,
      "variableName": "title",
      "defaultValue": "精品课程",
      "x": 50, "y": 60, "width": 500, "height": 50,
      "zIndex": 10, "sortOrder": 1,
      "fontSize": 28, "fontColor": "#1A1A1A",
      "fontWeight": "bold", "textAlign": "center"
    },
    {
      "elementType": "qrcode",
      "elementKey": "qr_code",
      "elementName": "分享二维码",
      "isVariable": false,
      "qrContentMode": "url_with_invite",
      "qrBaseUrl": "https://v.joho.cn/share",
      "qrInviteParam": "inviteCode",
      "qrInviteSeparator": "?",
      "qrFallbackMode": "base_url_only",
      "qrErrorLevel": "M",
      "qrSize": 120,
      "x": 240, "y": 800, "width": 120, "height": 120,
      "zIndex": 10, "sortOrder": 5
    }
  ]
}
成功响应
返回 { "data": [ ...createdElements ] }，包含所有新创建的元素（含新的 documentId）。
先删后建策略说明
1. 查询该模板下所有现有元素 (filters: { posterTemplate: templateDocumentId })
2. 逐一删除现有元素
3. 遍历传入的元素数组，为每个元素附加 posterTemplate: templateDocumentId 后创建
4. 返回新创建的元素数组
错误后果
由于先删后建，如果创建过程中出错（如网络中断），已删除的元素无法恢复。建议在批量保存前确认元素数据完整。

5.5 模板克隆 API

POST /admin/poster-templates/:id/clone 管理端 API 需认证
用途
基于现有模板创建副本，完整复制模板属性和所有关联元素。
请求体
无需请求体，仅需路径参数 id（原模板的 documentId）。
成功响应
返回 { "data": { ...clonedTemplate } }，包含克隆的模板及其元素。
克隆后的字段变化
name：追加 "(副本)" 后缀，如 "默认课程分享海报 (副本)"
code：追加 _copy_{timestamp} 后缀，如 course_share_default_copy_1691491200000
isDefault：强制设为 false
其他字段：完全复制原模板的值
元素：逐一复制，新元素的 posterTemplate 指向克隆模板的 documentId
失败响应 (400)
{ "error": { "code": "POSTER_400", "message": "Template not found" } }
克隆后操作

克隆完成后，新模板的 code 包含时间戳后缀，不便于记忆和使用。建议克隆后立即调用 PUT /admin/poster-templates/:id 修改 name 和 code 为有意义的值。同时检查 isActive 状态，如果不需要立即可用，设为 false。

5.6 元素管理 API

除了通过批量保存 API 管理元素外，系统还提供单个元素的 CRUD API。这些 API 所需权限为 zhao-studio.poster-element.manage。

方法路径用途
GET/admin/poster-elements查询元素列表（支持 filters 过滤）
POST/admin/poster-elements创建单个元素
PUT/admin/poster-elements/:id更新单个元素
DELETE/admin/poster-elements/:id删除单个元素
推荐使用方式

管理后台的 PosterTemplatePage 使用批量保存 API（PUT /admin/poster-templates/:id/elements）管理元素，而非单个元素 CRUD。批量保存的优势是原子性更好（一次性保存所有元素），且前端状态管理更简单。单个元素 CRUD API 适用于需要精确控制单个元素的场景，如通过外部脚本批量导入元素。

5.7 前端集成完整示例

前端 Canvas 渲染完整流程

Step 1: 调用渲染 API

// 调用渲染 API 获取已解析的元素配置
const response = await fetch('/api/zhao-studio/v1/posters/render', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    templateCode: 'course_share_default',
    variables: {
      title: 'React 进阶实战课程',
      description: '从入门到精通，12 周系统学习',
      image_url: 'https://cdn.example.com/course/react.jpg',
      qr_code: 'https://v.joho.cn/share',
      sale_price: '299',
      invite_code: 'USER_ABC123'
    }
  })
});

const { data } = await response.json();
const { template, elements } = data;

Step 2: Canvas 渲染

// 使用 Canvas API 渲染海报
const canvas = document.createElement('canvas');
canvas.width = template.canvasWidth;
canvas.height = template.canvasHeight;
const ctx = canvas.getContext('2d');

// 1. 绘制背景
ctx.fillStyle = template.backgroundColor || '#FFFFFF';
ctx.fillRect(0, 0, canvas.width, canvas.height);

// 2. 绘制背景图片（如有）
if (template.backgroundImage) {
  const bgImg = await loadImage(template.backgroundImage);
  // 根据 backgroundMode 绘制（此处以 cover 为例）
  drawImageCover(ctx, bgImg, 0, 0, canvas.width, canvas.height);
}

// 3. 按顺序绘制元素
for (const el of elements) {
  ctx.save();

  // 设置透明度
  ctx.globalAlpha = el.opacity ?? 1;

  // 设置旋转
  if (el.rotation) {
    ctx.translate(el.x, el.y);
    ctx.rotate(el.rotation * Math.PI / 180);
    ctx.translate(-el.x, -el.y);
  }

  // 根据元素类型绘制
  switch (el.elementType) {
    case 'text':
      ctx.font = `${el.fontWeight} ${el.fontSize}px ${el.fontFamily}`;
      ctx.fillStyle = el.fontColor;
      ctx.textAlign = el.textAlign;
      ctx.fillText(el.resolvedContent, el.x, el.y + el.fontSize);
      break;

    case 'image':
      const img = await loadImage(el.resolvedContent);
      // 根据 imageFit 绘制
      ctx.drawImage(img, el.x, el.y, el.width, el.height);
      break;

    case 'qrcode':
      // 使用二维码库（如 qrcode.js）生成二维码
      await drawQRCode(ctx, el.resolvedContent, el.x, el.y,
        el.qrSize, el.qrColor, el.qrBgColor, el.qrErrorLevel);
      break;

    case 'shape':
      ctx.fillStyle = el.elementBgColor || 'transparent';
      if (el.shapeType === 'rect') {
        drawRoundRect(ctx, el.x, el.y, el.width, el.height, el.borderRadius);
        ctx.fill();
      } else if (el.shapeType === 'circle') {
        ctx.beginPath();
        ctx.arc(el.x + el.width/2, el.y + el.height/2,
          Math.min(el.width, el.height)/2, 0, Math.PI * 2);
        ctx.fill();
      }
      break;
  }

  ctx.restore();
}

// 4. 导出图片
const posterImage = canvas.toDataURL('image/png');

5.9 管理后台 API 工具类

管理后台前端通过 posterApi.ts 工具类封装了所有管理端 API 调用。该工具类的基础路径为 /api/zhao-studio/v1/admin，提供以下方法：

方法API 调用说明
posterApi.listTemplates(filters?)GET /poster-templates查询模板列表，可选 filters 参数
posterApi.createTemplate(data)POST /poster-templates创建模板
posterApi.findOneTemplate(id)GET /poster-templates/:id查询单个模板详情
posterApi.updateTemplate(id, data)PUT /poster-templates/:id更新模板
posterApi.deleteTemplate(id)DELETE /poster-templates/:id删除模板
posterApi.cloneTemplate(id)POST /poster-templates/:id/clone克隆模板
posterApi.batchSaveElements(templateId, elements)PUT /poster-templates/:id/elements批量保存元素

此外，usePosterTemplates Hook 在 posterApi 基础上封装了 React 状态管理，提供 templates 状态和自动刷新机制。每次 create/update/delete/clone/batchSave 操作完成后自动调用 fetchTemplates() 刷新列表。

最佳实践

管理后台使用 usePosterTemplates Hook 管理模板状态，使用 posterApi 直接调用特定 API。前端 C 端使用公开 API（GET /posters/templates/:code 和 POST /posters/render），无需认证和权限。API 返回的元素配置可以直接用于 Canvas 渲染，无需额外处理。
