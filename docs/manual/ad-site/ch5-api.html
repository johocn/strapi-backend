第五章前端API集成

5.1 公开 API 总览

站内广告系统提供两类 API：公开 API（无需认证，供前端页面拉取广告数据）和管理 API（需认证，供管理后台进行 CRUD 操作）。公开 API 是前端集成的主要接口，管理 API 用于后台管理系统。

API 类型端点方法认证用途
公开 API/api/ads/zones/:positionGET无需按位置获取广告区域及其有效内容
公开 API/api/ads/zonesGET无需获取当前站点的所有活跃广告区域
管理 API/api/ad-zonesGET/POST需要广告区域列表查询与创建
管理 API/api/ad-zones/:idGET/PUT/DELETE需要广告区域详情查询、更新、删除
管理 API/api/ad-contentsGET/POST需要广告内容列表查询与创建
管理 API/api/ad-contents/:idGET/PUT/DELETE需要广告内容详情查询、更新、删除

API 请求与响应通用规范

项目说明
基础 URLhttps://your-domain.com/api
内容类型application/json
字符编码UTF-8
站点识别通过请求头 X-Site-Code 或域名自动识别当前站点
用户标识频次控制通过请求头 X-User-Id 或 cookie 识别用户
响应格式JSON，成功返回数据对象，失败返回 error 对象
分页管理 API 支持 ?page=1&pageSize=25 分页参数

5.2 按位置获取广告

GET /api/ads/zones/:position 是前端最常用的 API，通过 position 路径参数获取指定位置的广告区域及其有效内容。前端页面在对应位置加载时调用此接口，获取广告数据后渲染到页面。

请求参数

参数位置参数名类型必填说明
路径positionstring是广告位置标识，如 home-banner、article-bottom
请求头X-Site-Codestring否站点编码，多站点系统必传。单站点可不传
请求头X-User-Idstring否用户标识，用于频次控制。未传则不做频次限制
查询limitinteger否返回内容数量上限，默认返回全部有效内容

请求示例

GET /api/ads/zones/home-banner HTTP/1.1
Host: your-domain.com
X-Site-Code: main

空响应处理

当指定位置没有活跃区域或没有有效内容时，API 返回：

  "id": null,
  "name": null,
  "position": "home-banner",
  "displayMode": null,
  "adContents": []
}

前端组件应处理空响应情况，当 adContents 为空数组时不渲染广告区域（不展示空容器）。

5.4 管理 API（CRUD）

管理 API 用于后台管理系统对广告区域和广告内容进行增删改查操作。所有管理 API 需要认证（Bearer Token），且需要对应的权限。

广告区域管理 API

操作方法端点说明
区域列表GET/api/ad-zones?populate=*&code>&page=1&pageSize=25分页查询区域列表，支持 populate 关联数据
区域详情GET/api/ad-zones/:id?populate=adContents查询单个区域详情，可 populate 关联的广告内容
创建区域POST/api/ad-zones创建新广告区域，请求体包含字段数据
更新区域PUT/api/ad-zones/:id更新广告区域字段
删除区域DELETE/api/ad-zones/:id删除广告区域（注意：不会自动删除关联内容）

5.5 前端组件集成

前端集成广告系统的推荐方式是封装统一的 AdZone 组件，在页面中通过 position 属性引用广告区域。组件内部调用公开 API 获取数据，根据 displayMode 和 displayStyle 自动渲染对应内容。

AdZone 组件设计

<!-- AdZone.vue -->
<template>
  <div v-if="zone && zone.adContents && zone.adContents.length > 0"
       class="ad-zone"
       :class="`ad-zone--${zone.position}`"
       :style="zoneStyle">

    <!-- single 模式：只展示第一条 -->
    <template v-if="zone.displayMode === 'single'">
      <AdContent :content="zone.adContents[0]" />
    </template>

    <!-- rotation 模式：轮播展示 -->
    <template v-else-if="zone.displayMode === 'rotation'">
      <AdRotation :contents="zone.adContents" :interval="5000" />
    </template>

    <!-- slideshow 模式：幻灯片展示 -->
    <template v-else-if="zone.displayMode === 'slideshow'">
      <AdSlideshow :contents="zone.adContents" />
    </template>

    <!-- stack 模式：堆叠展示 -->
    <template v-else-if="zone.displayMode === 'stack'">
      <AdContent v-for="content in zone.adContents"
                 :key="content.id"
                 :content="content" />
    </template>
  </div>
</template>

<script setup>
import { ref, onMounted, computed } from 'vue'

const props = defineProps({
  position: { type: String, required: true }
})

const zone = ref(null)

const zoneStyle = computed(() => ({
  width: zone.value?.suggestedWidth ? zone.value.suggestedWidth + 'px' : '100%',
  minHeight: zone.value?.suggestedHeight ? zone.value.suggestedHeight + 'px' : 'auto'
}))

onMounted(async () => {
  try {
    const res = await fetch(`/api/ads/zones/${props.position}`, {
      headers: {
        'X-Site-Code': window.__SITE_CODE__ || '',
        'X-User-Id': getUserId()
      }
    })
    zone.value = await res.json()
  } catch (e) {
    console.error('Failed to load ad zone:', e)
  }
})

function getUserId() {
  // 从 cookie 或 localStorage 获取用户标识
  return localStorage.getItem('user_id') || generateAnonymousId()
}
</script>

AdContent 渲染组件设计

<!-- AdContent.vue -->
<template>
  <div class="ad-content"
       :class="`ad-content--${content.displayStyle}`"
       :style="contentStyle"
       @click="handleClick">

    <!-- 素材层 -->
    <template v-if="content.contentType === 'single-image'">
      <img :src="content.images[0]?.url"
           :alt="content.images[0]?.alt"
           class="ad-image" />
    </template>

    <template v-else-if="content.contentType === 'video'">
      <video :src="content.videoUrl"
             :poster="content.videoPoster"
             :autoplay="content.videoAutoplay"
             :muted="content.videoMuted"
             :loop="content.videoLoop"
             :controls="content.videoControls"
             class="ad-video" />
    </template>

    <template v-else-if="content.contentType === 'html'">
      <div v-html="content.htmlContent" class="ad-html"></div>
    </template>

    <!-- 文字层 -->
    <div class="ad-overlay" v-if="content.title || content.subtitle">
      <h3 v-if="content.title"
          :style="titleStyle">{{ content.title }}</h3>
      <p v-if="content.subtitle"
         :style="subtitleStyle">{{ content.subtitle }}</p>
    </div>

    <!-- CTA 按钮 -->
    <button v-if="content.ctaText"
            class="ad-cta"
            :style="ctaStyle">{{ content.ctaText }}</button>

    <!-- 角标 -->
    <span v-if="content.badgeText"
          class="ad-badge"
          :class="`ad-badge--${content.badgePosition}`"
          :style="badgeStyle">{{ content.badgeText }}</span>
  </div>
</template>

<script setup>
import { computed } from 'vue'

const props = defineProps({
  content: { type: Object, required: true }
})

const contentStyle = computed(() => ({
  width: props.content.width ? props.content.width + 'px' : '100%',
  height: props.content.height ? props.content.height + 'px' : 'auto',
  borderRadius: props.content.borderRadius ? props.content.borderRadius + 'px' : '0',
  backgroundColor: props.content.backgroundColor || 'transparent'
}))

const titleStyle = computed(() => ({
  color: props.content.titleColor,
  fontSize: props.content.titleFontSize + 'px',
  fontWeight: props.content.titleFontWeight,
  textAlign: props.content.titleAlign,
  lineHeight: props.content.titleLineHeight
}))

const ctaStyle = computed(() => ({
  color: props.content.ctaTextColor,
  backgroundColor: props.content.ctaBgColor,
  fontSize: props.content.ctaFontSize + 'px',
  borderRadius: props.content.ctaBorderRadius + 'px'
}))

function handleClick() {
  if (props.content.linkType === 'none') return
  if (props.content.linkTarget === '_blank') {
    window.open(props.content.linkUrl, '_blank', 'noopener,noreferrer')
  } else {
    window.location.href = props.content.linkUrl
  }
}
</script>

Nuxt3 SSR 集成

在 Nuxt3 项目中，推荐使用 useFetch 进行 SSR 友好的广告数据获取：

// composables/useAdZone.ts
export function useAdZone(position: string) {
  const config = useRuntimeConfig()

  return useFetch(`/api/ads/zones/${position}`, {
    baseURL: config.public.apiBase,
    headers: {
      'X-Site-Code': config.public.siteCode
    },
    // 缓存 5 分钟，减少重复请求
    transform: (data) => data,
    server: true,  // SSR 时也请求
    lazy: false    // 不延迟加载
  })
}
<!-- 在页面中使用 -->
<script setup>
const { data: bannerZone } = useAdZone('home-banner')
const { data: sidebarZone } = useAdZone('home-sidebar')
</script>

<template>
  <AdZone v-if="bannerZone" :zone="bannerZone" />
  <AdZone v-if="sidebarZone" :zone="sidebarZone" />
</template>

5.6 错误处理与最佳实践

错误响应格式

HTTP 状态码错误原因错误信息处理建议
400请求参数错误{"error":{"message":"Invalid position value"}}检查 position 参数是否为有效枚举值
401未认证（管理 API）{"error":{"message":"Unauthorized"}}检查 Authorization 请求头
403无权限{"error":{"message":"Forbidden"}}检查用户角色权限
404区域或内容不存在{"error":{"message":"Not Found"}}检查 ID 是否正确
429请求频率超限{"error":{"message":"Too Many Requests"}}降低请求频率，添加缓存
500服务器内部错误{"error":{"message":"Internal Server Error"}}检查服务端日志

前端错误处理最佳实践

async function loadAdZone(position) {
  try {
    const res = await fetch(`/api/ads/zones/${position}`, {
      headers: getAdHeaders()
    })

    if (!res.ok) {
      // 非 200 响应，静默失败，不影响页面展示
      console.warn(`Ad zone "${position}" load failed:`, res.status)
      return null
    }

    const data = await res.json()

    // 空数据处理
    if (!data.adContents || data.adContents.length === 0) {
      return null
    }

    return data
  } catch (e) {
    // 网络错误，静默失败
    console.warn(`Ad zone "${position}" network error:`, e.message)
    return null
  }
}

性能优化最佳实践

优化项做法收益
请求缓存前端缓存 API 响应 5 分钟，避免重复请求减少 80%+ API 调用
懒加载视窗外的广告区域使用 Intersection Observer 懒加载加快首屏渲染
并行请求页面有多个广告位时并行请求，不串行总加载时间减少
骨架屏广告加载中展示骨架屏占位，避免布局偏移改善 CLS 指标
图片懒加载广告图片使用 loading="lazy"节省带宽
错误降级广告加载失败时静默处理，不影响页面内容保证核心内容可用

安全最佳实践

安全注意事项

1. HTML 内容 XSS 防护 — 渲染 htmlContent 前应进行 HTML 消毒（sanitize），移除 script 标签和事件属性。推荐使用 DOMPurify 库。2. 外部链接安全 — linkTarget=_blank 的链接应自动添加 rel="noopener noreferrer"。3. API 频率限制 — 服务端应对公开 API 设置频率限制（如每 IP 每分钟 60 次），防止滥用。4. 管理 API 权限 — 管理 API 应校验用户角色和权限，非管理员不可访问。

完整集成检查清单

  • 前端封装了 AdZone 组件，通过 position 属性引用广告区域
  • AdZone 组件处理了 displayMode 的四种模式（single/rotation/slideshow/stack）
  • AdContent 组件处理了 contentType 的五种类型（single-image/multi-image/slideshow/video/html）
  • htmlContent 渲染前进行了 XSS 消毒
  • 广告加载失败时静默处理，不影响页面核心内容
  • 广告图片使用了懒加载（loading="lazy"）
  • 视窗外广告区域使用了 Intersection Observer 懒加载
  • API 响应设置了前端缓存（5 分钟）
  • 频次控制通过 X-User-Id 请求头传递用户标识
  • 多站点系统通过 X-Site-Code 请求头传递站点标识
  • 外部链接自动添加了 rel="noopener noreferrer"
  • SSR 项目中广告数据在服务端预取
集成总结

前端广告集成的核心是AdZone 组件 + AdContent 组件的分层设计：AdZone 负责获取数据和选择排列策略（displayMode），AdContent 负责渲染单条广告的素材和样式（contentType + displayStyle）。通过 position 属性解耦页面位置与广告数据，运营人员在后台新增广告位后前端无需改动。遵循错误降级、懒加载和缓存原则，确保广告系统不影响页面核心性能和用户体验。
