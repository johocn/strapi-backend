第四章展示方式详解

4.1 展示样式总览

广告内容的 displayStyle 字段定义了单条广告在页面中的视觉呈现方式。系统提供六种展示样式，覆盖从静态横幅到全屏弹窗的全部场景。展示样式与广告区域的 displayMode 协同工作：displayMode 决定多条内容如何排列，displayStyle 决定每条内容如何呈现。

displayStyle展示方式容器特征推荐 position推荐 contentType
banner横幅展示全宽容器，固定高度，图片撑满home-banner, list-top, article-top, footersingle-image, slideshow
card卡片展示固定宽度卡片，带圆角和阴影home-sidebar, article-bottomsingle-image, multi-image
modal弹窗展示全屏遮罩层，居中内容容器popupsingle-image, html
inline内嵌展示融入内容流，无边框article-inlinesingle-image, html
float悬浮展示固定在视窗边缘，不随滚动移动floatsingle-image, html
fullscreen全屏展示覆盖整个视窗，强制展示popup, customsingle-image, video, html

4.2 Banner 横幅展示

Banner 是最常见的广告展示样式，以全宽横幅形式展示在页面顶部、底部或内容区之间。容器宽度通常为 100% 父容器宽度，高度由 height 字段或区域 suggestedHeight 决定。

属性说明默认行为
容器宽度100% 父容器宽度由父容器决定
容器高度由 height 或区域 suggestedHeight 决定300px（如未设置）
图片填充object-fit: cover，图片撑满容器居中裁剪
文字叠加标题/副标题/CTA 叠加在图片之上绝对定位居中
圆角由 borderRadius 控制0（全宽横幅无圆角）

首页顶部活动横幅
配置项值

displayModerotation（轮播）

4.3 Card 卡片展示

Card 样式以独立卡片形式展示广告，通常用于侧边栏、内容推荐区等位置。卡片有固定宽度、圆角和阴影，视觉上独立于页面内容。

属性说明默认行为
容器宽度由 width 或区域 suggestedWidth 决定300px（侧边栏场景）
容器高度自适应内容或由 height 决定auto
圆角由 borderRadius 控制12px
阴影box-shadow 轻微投影0 2px 8px rgba(0,0,0,0.1)
背景色由 backgroundColor 控制#ffffff
文字布局图片在上，文字在下（垂直排列）图片+文字垂直堆叠

Card 样式与 Banner 样式的核心区别：Banner 是图片铺满容器、文字叠加在图片上；Card 是图片和文字垂直分区排列，文字在图片下方独立展示。Card 更适合需要展示较多文字信息的广告。

4.4 Modal 弹窗展示

Modal 样式以弹窗形式展示广告，覆盖在页面内容之上。通常用于首次访问引导、活动公告、订阅引导等场景。弹窗包含全屏半透明遮罩层和居中的内容容器。

属性说明推荐值
遮罩层全屏半透明黑色背景rgba(0,0,0,0.6)
内容容器居中定位，固定宽度宽度 480-600px
关闭按钮右上角 X 按钮，受 closeDelay 控制closeDelay: 0-3000
倒计时showCountdown=true 时展示关闭倒计时配合 closeDelay 使用
频次控制必须配合 frequencyLimit 使用1 次/天
动画效果淡入+缩放进入动画前端默认实现
弹窗广告使用原则

1. 必须设置频次限制 — 弹窗广告必须配置 frequencyLimit 和 frequencyPeriod，推荐每天最多 1 次。不设频次的弹窗会导致用户严重反感。2. closeDelay 不超过 5 秒 — 强制展示时间过长会激怒用户。3. 提供明确的关闭方式 — 关闭按钮必须清晰可见，不应隐藏或伪装。4. 移动端适配 — 弹窗在移动端应自适应屏幕宽度，避免内容溢出。

4.5 Inline 内嵌展示

Inline 样式将广告无缝嵌入内容流中，通常用于文章段落之间、信息流中等场景。与 Banner 和 Card 不同，Inline 不使用独立容器边框，而是融入周围内容。

属性说明默认行为
容器无独立边框，融入内容流无边框无阴影
宽度100% 父容器宽度跟随内容区宽度
间距上下 margin 与段落间距一致margin: 24px 0
圆角可设置轻微圆角0-8px
标识可选"广告"标识小字右上角灰色"广告"字样

Inline 样式的核心价值是原生广告体验——广告看起来像是内容的一部分而非硬植入。适合文章中间的产品推荐、相关阅读引导等场景。使用时应确保广告内容与上下文章节主题相关，避免突兀。

4.6 Float 悬浮展示

Float 样式将广告固定在浏览器视窗的边缘位置，不随页面滚动而移动。通常用于客服入口、返回顶部、悬浮广告条等场景。

属性说明推荐值
定位方式position: fixed，固定在视窗边缘bottom-right 或 bottom-left
容器尺寸小尺寸固定容器60x60 ~ 120x120
层级z-index 较高，覆盖在内容之上z-index: 9999
关闭按钮提供关闭按钮，可配合 closeDelaycloseDelay: 0
频次控制建议设置频次限制3-5 次/会话
移动端移动端可能隐藏或缩小视情况适配
Float 悬浮广告位置建议

悬浮广告推荐放在右下角（bottom-right），避免遮挡页面核心内容。左下角可能遮挡移动端浏览器的返回按钮。尺寸不宜过大（不超过 120x120），否则遮挡内容面积过多。建议提供关闭按钮，关闭后当前会话不再展示。

4.7 Fullscreen 全屏展示

Fullscreen 样式以全屏覆盖方式展示广告，通常用于开屏广告（App 启动广告的 Web 版本）或全屏引导页。广告覆盖整个浏览器视窗，用户必须等待或主动关闭后才能访问页面内容。

属性说明推荐值
覆盖范围100vw x 100vh，全屏覆盖全视窗
背景图片或视频铺满全屏object-fit: cover
关闭按钮必须提供，受 closeDelay 控制closeDelay: 3000-5000
跳过按钮倒计时结束后可跳过showCountdown: true
频次控制必须严格控制频次1 次/天
展示时长建议 3-5 秒后自动关闭配合 closeDelay
全屏广告使用警告

全屏广告对用户体验影响最大，使用时必须极其谨慎：1. 频次严格控制 — 每天最多展示 1 次。2. 展示时间限制 — 不超过 5 秒，超时自动关闭。3. 明确的跳过方式 — 必须提供跳过按钮，不得强制观看。4. 首次访问优先 — 仅对首次访问用户展示，老用户不应频繁看到。5. 移动端慎用 — 移动端全屏广告对用户干扰更大，建议仅在活动期间启用。

4.8 轮播设置详解

当 contentType=slideshow 时，广告内容以幻灯片形式展示多张图片。轮播设置控制幻灯片的播放行为，包括自动播放、切换间隔、切换效果、循环模式、导航控件等。

轮播字段详解

字段类型说明推荐值
slideshowAutoplayboolean是否自动播放。true 时页面加载后自动开始轮播true
slideshowIntervalinteger自动播放间隔（毫秒）。每张图片展示的时长5000（5 秒）
slideshowEffectenumeration切换动画效果fade
slideshowLoopboolean是否循环播放。false 时播完最后一张停止true
slideshowShowDotsboolean是否显示底部指示点（当前页/总页数）true
slideshowShowArrowsboolean是否显示左右切换箭头true（PC）/ false（移动端）
slideshowPauseOnHoverboolean鼠标悬停时是否暂停自动播放true

切换效果对比

slideshowEffect效果描述视觉感受性能适用场景
fade淡入淡出：当前图片淡出，下一张淡入柔和优雅高（仅 opacity 变化）品牌展示、活动合集
slide滑动：图片水平/垂直滑动切换动态有节奏中（需 transform 动画）产品展示、多图浏览

轮播间隔设置原则

轮播间隔（slideshowInterval）应确保用户有足够时间阅读每张图片上的文字内容。经验值：纯图片无文字 3000-4000ms 即可，含短标题 4000-5000ms，含标题+副标题+CTA 建议 5000-6000ms。间隔过短（<3000ms）用户来不及阅读，过长（>8000ms）用户可能以为广告卡住。

4.9 视频设置详解

当 contentType=video 时，广告内容以视频形式展示。视频广告设置控制视频的播放行为，包括封面图、自动播放、静音、循环和控件显示。

视频字段详解

字段类型说明推荐值
videoUrlstring视频文件 URL，支持 MP4/WebMCDN 加速的 HTTPS URL
videoPosterstring视频封面图 URL，视频加载前展示与视频同比例的 JPG
videoAutoplayboolean是否自动播放true（配合 muted）
videoMutedboolean是否静音播放true（如 autoplay=true）
videoLoopboolean是否循环播放true（横幅视频）
videoControlsboolean是否显示播放控件false（横幅）/ true（内容区）

自动播放策略详解

videoAutoplayvideoMuted浏览器行为推荐场景
truetrue静音自动播放（大多数浏览器允许）首页横幅视频广告
truefalse有声自动播放（浏览器阻止，不会自动播放）不推荐
falsefalse不自动播放，用户点击播放（有声）文章内嵌视频广告
falsetrue不自动播放，用户点击播放（静音）不推荐（用户困惑）
浏览器自动播放策略

Chrome（66+）、Safari（11+）、Firefox（66+）均实施了自动播放策略：静音视频可以自动播放，有声视频需要用户交互后才能播放。因此，如需视频广告自动播放，必须设置 videoAutoplay=true 且 videoMuted=true。用户可以通过点击取消静音（需前端组件实现此交互）。

视频广告技术规范

规范项要求原因

视频时长15-30 秒广告时长适中，用户耐心有限
文件大小<5MB加载速度，移动端流量
分辨率720p（1280x720）清晰度与文件大小平衡
封面图与视频同比例，JPG/WebP视频加载前的视觉占位

4.10 自定义 HTML

当 contentType=html 时，广告内容通过 htmlContent 字段渲染自定义 HTML 代码。这是最灵活的内容类型，可以实现图片和视频无法覆盖的复杂交互广告，如动画效果、表单交互、第三方组件嵌入等。

htmlContent 使用规范

规范项要求说明
样式使用内联 style 或 <style> 标签不引用外部 CSS 文件
脚本使用内联 <script> 标签不引用外部 JS 文件（如必须，确保 HTTPS）
结构自包含 HTML 片段不含 html/head/body 标签
代码量控制在 5KB 以内过大影响页面加载
安全内容来源可信防止 XSS 注入
响应式适配不同屏幕宽度使用相对单位或媒体查询

自定义 HTML 应用场景

场景HTML 内容displayStyle
动画广告CSS/JS 动画效果，粒子、渐变、变形banner
互动表单广告订阅表单、问卷、预约表单modal
第三方组件嵌入第三方广告联盟代码banner / inline
倒计时广告JS 倒计时组件，活动倒计时banner / modal
游戏化广告简单互动小游戏，完成后领取优惠modal / fullscreen
自定义 HTML 安全警告

1. 仅使用可信来源的 HTML 代码 — htmlContent 通过 v-html/innerHTML 渲染，如果包含恶意代码会导致 XSS 攻击。确保代码来源可信，不接受外部用户提交的 HTML。2. 避免全局样式污染 — HTML 中的 CSS 不应使用全局选择器（如 body {}），应使用 scoped 类名。3. 避免影响页面布局 — HTML 中的元素不应脱离广告容器范围（如 position: fixed 可能覆盖整个页面）。4. 性能注意 — 复杂的 JS 动画可能影响页面性能，在低端设备上测试。

自定义 HTML 示例

以下是一个简单的倒计时广告 HTML 示例：

<div style="position:relative;width:100%;height:300px;background:linear-gradient(135deg,#667eea,#764ba2);border-radius:12px;overflow:hidden;display:flex;flex-direction:column;align-items:center;justify-content:center;color:#fff;font-family:sans-serif;">
  <h2 style="font-size:28px;margin:0 0 8px;">限时特惠</h2>
  <p style="font-size:16px;margin:0 0 20px;opacity:0.9;">活动剩余时间</p>
  <div id="countdown" style="font-size:36px;font-weight:700;letter-spacing:2px;">--:--:--</div>
  <a href="/sale" style="margin-top:20px;padding:10px 32px;background:#fff;color:#764ba2;border-radius:24px;text-decoration:none;font-weight:600;">立即抢购</a>
</div>
<script>
  (function(){
    var end = new Date('2026-11-11T23:59:59').getTime();
    var el = document.getElementById('countdown');
    function update(){
      var now = Date.now();
      var diff = Math.max(0, end - now);
      var h = Math.floor(diff/3600000);
      var m = Math.floor(diff%3600000/60000);
      var s = Math.floor(diff%60000/1000);
      el.textContent = [h,m,s].map(function(n){return String(n).padStart(2,'0')}).join(':');
    }
    update(); setInterval(update, 1000);
  })();
</script>
展示方式选择最佳实践

选择展示样式时遵循"位置匹配、内容适配、体验优先"原则：位置匹配——displayStyle 与 position 对应（home-banner 用 banner，popup 用 modal）；内容适配——displayStyle 与 contentType 协调（banner 适合 single-image/slideshow，modal 适合 single-image/html）；体验优先——干扰性强的样式（modal、fullscreen）必须配合频次控制和关闭机制。正确选择展示样式是广告效果和用户体验平衡的关键。
