第三章广告内容配置

3.1 设计目的与核心概念

广告内容（ad-content）是站内广告系统的运营资产层。如果说广告区域定义了"广告展示在哪里"，那么广告内容定义了"广告展示什么"以及"内容如何呈现"。每一条广告内容记录代表一条可展示的广告，包含素材资源、文字样式、交互行为、定时规则和频次策略等完整配置。

广告内容支持五种内容类型：single-image（单图广告）、multi-image（多图广告）、slideshow（幻灯片广告）、video（视频广告）、html（自定义 HTML 广告）。每种类型对应不同的素材字段和渲染逻辑，覆盖了从静态图片到富媒体交互的全场景需求。

广告内容的配置能力分为五个维度：素材维度（图片、视频、HTML）、文字维度（标题、副标题、CTA 按钮、角标）、交互维度（链接跳转、弹窗关闭、倒计时）、时间维度（定时投放、频次控制）、样式维度（展示样式、尺寸、圆角、背景色）。这五个维度组合出丰富的广告展示效果。

基础信息字段

name string 必填 广告核心
设计初衷
广告内容的显示名称，用于管理后台列表展示和运营人员识别。
作用原理
仅在管理后台展示，不出现在公开 API 返回数据中。运营人员通过名称区分同一区域下的不同广告内容。
标准填写规范
使用"活动名+内容类型"的命名格式，如"双十一促销-单图""新品发布-视频""品牌周年庆-幻灯片"。名称应直观反映广告内容和类型。
错误后果
名称含糊时，运营人员无法在列表中快速定位目标广告，管理效率降低。
adZone relation → ad-zone 必填 广告核心
设计初衷
关联到广告区域，将广告内容挂载到指定区域。这是区域与内容一对多关系的正向引用。
作用原理
创建内容时选择所属区域，系统自动在区域的 adContents 列表中添加该内容。API 查询区域时返回其下所有有效内容。
标准填写规范
选择与广告展示位置匹配的区域。如"首页横幅"广告内容应关联到 position=home-banner 的区域。
错误后果
未关联区域的内容成为孤立数据，无法被 API 查询到；关联错误区域时广告展示在错误位置。
site relation → site 必填 多租户
设计初衷
关联到 site 内容类型，实现多租户数据隔离。内容所属站点应与关联区域的站点一致。
作用原理
公开 API 查询时按站点上下文过滤内容。管理后台可按 site 筛选内容列表。
标准填写规范
与关联的 adZone 保持相同的 site。系统通常在创建时自动继承区域的 site，但仍需确认。
contentType enumeration 必填 广告核心
设计初衷
定义广告内容类型，决定使用哪些素材字段和前端渲染器。
作用原理
前端组件根据 contentType 选择渲染逻辑：single-image 渲染单图，multi-image 渲染多图网格，slideshow 渲染幻灯片，video 渲染视频播放器，html 渲染自定义 HTML。
标准填写规范
根据广告素材类型选择：单张推广图选 single-image，多张产品图选 multi-image，轮播活动图选 slideshow，视频素材选 video，复杂交互内容选 html。
错误后果
contentType 与实际素材不匹配时前端渲染异常：如选 single-image 但上传了多张图，只有第一张会展示；选 video 但未填写 videoUrl 时广告区域空白。
isActive boolean / default:true 必填 广告核心
设计初衷
控制广告内容是否参与展示。设为 false 时该内容不会出现在 API 返回结果中。
作用原理
API 查询时过滤掉 isActive=false 的内容。用于临时下线广告而无需删除记录。
标准填写规范
正式投放的广告设为 true。素材待替换、配置未完成的广告设为 false。活动结束后将相关广告设为 false 而非删除。
sortOrder / priority integer 选填 广告核心
设计初衷
sortOrder 控制同优先级内容的排列顺序（升序）；priority 控制内容的展示优先级（降序，值越大越优先）。
作用原理
API 返回内容时先按 priority 降序排列，同 priority 再按 sortOrder 升序排列。single 模式下只展示排序第一的内容。
标准填写规范
主推广告设高 priority（如 100），常规广告设中等 priority（如 50），备选广告设低 priority（如 10）。同 priority 内用 sortOrder 微调顺序（0, 1, 2...）。
错误后果
所有内容设置相同 priority 和 sortOrder 时，展示顺序不确定；single 模式下未正确设置 priority 可能展示非预期广告。

定时频次字段

startAt / endAt datetime 选填 定时
设计初衷
定义广告内容的投放时间段。startAt 为投放开始时间，endAt 为投放结束时间。未设置则不限制时间。
作用原理
API 查询时检查当前时间是否在 [startAt, endAt] 区间内。未设置 startAt 视为立即开始，未设置 endAt 视为永不结束。
标准填写规范
活动广告设置 startAt 为活动开始时间，endAt 为活动结束时间。长期广告不设置 endAt。使用 ISO 8601 格式（如 2026-11-11T00:00:00.000Z）。
错误后果
时区设置错误导致广告在错误时间展示；忘记设置 endAt 导致活动广告在活动结束后继续展示；startAt 设为未来时间时广告在创建后不会立即展示。
frequencyLimit / frequencyPeriod integer / enumeration 选填 频次
设计初衷
控制同一用户在指定时间周期内看到该广告的次数上限，避免过度曝光引起用户反感。
作用原理
frequencyLimit 为展示次数上限（如 3 次），frequencyPeriod 为统计周期（如每天、每小时）。前端通过用户标识（cookie/userId）记录展示次数，达到上限后不再返回该内容。
标准填写规范
弹窗广告建议 frequencyLimit=1, frequencyPeriod=day（每天最多展示 1 次）；横幅广告建议 frequencyLimit=5, frequencyPeriod=session（单次会话最多 5 次）。未设置则不限制频次。
错误后果
频次设置过低导致广告曝光不足；频次设置过高（或不设）导致弹窗广告反复弹出，严重影响用户体验。

素材内容字段

images JSON array 选填 素材
设计初衷
广告图片素材列表，JSON 数组格式。根据 contentType 决定使用方式：single-image 取第一张，multi-image 展示全部，slideshow 轮播展示。
作用原理
前端组件根据 contentType 从 images 数组中取图渲染。每张图片包含 url、alt、width、height 等属性。
标准填写规范
图片尺寸应与区域的 suggestedWidth/suggestedHeight 匹配。single-image 提供 1 张，multi-image 提供 2-6 张，slideshow 提供 3-8 张。格式 JPG/WebP/PNG，单张不超过 200KB。JSON 格式示例：[{"url":"https://...","alt":"活动图","width":1200,"height":300}]
错误后果
图片尺寸不匹配区域建议尺寸时展示变形或留白；图片过大导致页面加载缓慢；images 为空且 contentType 非 html/video 时广告区域空白。
videoUrl string 选填 素材
设计初衷
视频广告的播放地址。仅在 contentType=video 时使用。支持 MP4、WebM 等主流视频格式。
作用原理
前端渲染 video 标签，src 指向此 URL。配合 videoPoster（封面图）、videoAutoplay（自动播放）等字段控制播放行为。
标准填写规范
使用 CDN 加速的视频 URL，格式 MP4（兼容性最好）。视频时长建议 15-30 秒，文件大小不超过 5MB。URL 需支持 HTTPS 和跨域访问。
错误后果
URL 无效或跨域限制导致视频无法播放；视频文件过大导致加载缓慢，用户流失；格式不兼容（如仅提供 MOV）导致部分浏览器无法播放。
字段类型说明默认值
videoPosterstring视频封面图 URL，视频加载前展示-
videoAutoplayboolean是否自动播放（注意浏览器自动播放策略限制）false
videoMutedboolean是否静音播放（自动播放通常需静音）false
videoLoopboolean是否循环播放false
videoControlsboolean是否显示播放控件（进度条、音量等）true
自动播放策略注意

大多数现代浏览器（Chrome、Safari、Firefox）限制带声音的自动播放。如需自动播放，必须同时设置 videoAutoplay=true 和 videoMuted=true，否则浏览器会阻止自动播放。建议视频广告默认静音自动播放，用户点击后取消静音。

htmlContent text 选填 素材
设计初衷
自定义 HTML 广告内容。仅在 contentType=html 时使用。用于实现图片和视频无法覆盖的复杂交互广告。
作用原理
前端组件使用 v-html 或 innerHTML 将此字段内容渲染到广告容器中。支持内联 CSS 和 JavaScript。
标准填写规范
使用内联样式（非外部 CSS 文件引用）。HTML 结构应自包含，不依赖外部资源。代码量建议控制在 5KB 以内。注意 XSS 防护，仅在可信来源下使用。
错误后果
包含外部 CSS/JS 引用可能导致加载失败或跨域问题；HTML 结构不完整可能导致页面布局错乱；恶意代码注入风险（需确保内容来源可信）。

链接配置字段

linkType enumeration 选填 交互
设计初衷
定义广告点击后的跳转行为类型。
作用原理
枚举值：none（不可点击，纯展示型广告）、internal（站内跳转，URL 为相对路径）、external（外部跳转，URL 为完整 https 地址）。
标准填写规范
需要跳转的广告选 internal 或 external，配合 linkUrl 和 linkTarget 使用。纯展示型广告（如品牌形象）选 none。默认值为 none。
字段类型说明示例值
linkUrlstring跳转目标 URL。internal 为相对路径，external 为完整 URL/products/123 或 https://...
linkTargetstring链接打开方式：_self（当前页）或 _blank（新标签页）_blank

站内跳转建议使用 _self（当前页打开），站外跳转使用 _blank（新标签页打开）。external 链接建议添加 rel="noopener noreferrer" 属性（前端组件应自动处理）。

轮播设置最佳实践

首页横幅轮播建议：autoplay=true, interval=5000, effect=fade, loop=true, showDots=true, showArrows=true, pauseOnHover=true。移动端可考虑 interval=4000（略快），showArrows=false（节省空间）。自动播放间隔不宜过短（<3000ms），避免用户来不及阅读。

弹窗/悬浮交互字段

字段类型说明默认值
closeDelayinteger关闭按钮延迟显示时间（毫秒）。0 为立即可关闭0
showCountdownboolean是否显示倒计时（配合 closeDelay 使用，展示"X 秒后可关闭"）false

closeDelay 用于弹窗广告强制展示一定时间后才能关闭，确保用户看到广告内容。如设置 closeDelay=3000，弹窗展示 3 秒后才出现关闭按钮。showCountdown 设为 true 时展示倒计时数字，提升用户体验（让用户知道何时可以关闭）。

弹窗广告用户体验注意

弹窗广告的 closeDelay 不建议超过 5 秒，过长的强制展示时间会严重影响用户体验，增加跳出率。对于首次访问用户的引导弹窗，建议 closeDelay=0（立即可关闭）配合 frequencyLimit=1, frequencyPeriod=day（每天最多弹一次）。

3.5 标准创建全流程

素材准备清单

素材要求用途
广告图片尺寸匹配区域建议尺寸, JPG/WebP, <200KB/张填入 images
视频文件（可选）MP4 格式, <5MB, 15-30 秒填入 videoUrl
视频封面（可选）与视频同比例, JPG/WebP填入 videoPoster
标题文案20 字以内, 简洁有力填入 title
副标题文案30 字以内, 补充说明填入 subtitle
CTA 按钮文案动词开头, 2-6 字填入 ctaText

填写顺序

  1. 基础信息 — 填写 name，选择 adZone 和 site，选择 contentType
  2. 素材内容 — 根据 contentType 填写对应素材：images（图片类）/ videoUrl+videoPoster（视频）/ htmlContent（HTML）
  3. 文字内容 — 填写 title、subtitle、ctaText、badgeText
  4. 文字样式 — 配置标题、副标题、CTA、角标的颜色/字号/位置等样式字段
  5. 展示样式 — 选择 displayStyle，设置 width/height/borderRadius/backgroundColor
  6. 链接配置 — 设置 linkType、linkUrl、linkTarget
  7. 轮播设置（如 contentType=slideshow）— 配置 slideshowAutoplay、slideshowInterval、slideshowEffect 等
  8. 弹窗交互（如 displayStyle=modal/float）— 设置 closeDelay、showCountdown
  9. 定时频次 — 设置 startAt/endAt、frequencyLimit/frequencyPeriod
  10. 排序优先级 — 设置 priority 和 sortOrder
  11. 自检 — 对照自检清单逐项检查
  12. 上线 — 确认 isActive=true，保存

创建前自检清单

  • name 使用"活动名+内容类型"格式
  • adZone 已正确关联到目标区域
  • site 与 adZone 的 site 一致
  • contentType 与素材字段匹配
  • images 尺寸与区域 suggestedWidth/suggestedHeight 匹配
  • videoUrl 有效且格式为 MP4（如使用视频）
  • title 不超过 20 字，副标题不超过 30 字
  • CTA 按钮文案为动词开头短句
  • displayStyle 与区域 position 匹配
  • linkType 和 linkUrl 配置一致
  • 定时设置正确（startAt < endAt）
  • 频次设置合理（弹窗不超过 1 次/天）
  • priority 已设置，区分主推和备选广告
  • isActive 设为 true

3.6 发布后闭环运作与禁忌

前端展示效果

广告内容创建并激活后，前端通过区域 API 获取到该内容数据。组件根据 contentType 选择渲染器：single-image 渲染单张图片加文字层；multi-image 渲染多图网格；slideshow 渲染幻灯片组件；video 渲染视频播放器；html 渲染自定义 HTML。文字层（标题、副标题、CTA、角标）叠加在素材之上，样式由对应字段控制。用户点击广告时根据 linkType 和 linkUrl 执行跳转。

字段禁忌写法

字段禁忌写法后果
contentType选 video 但不填 videoUrl广告区域空白，视频播放器无内容
images图片尺寸与区域建议尺寸差异过大图片变形、拉伸或留白
title超过 50 字的长标题文字溢出容器，展示效果差
startAt/endAtstartAt > endAt广告永远不会展示（时间段无效）
frequencyLimit弹窗广告不设频次限制每次页面加载都弹出，用户严重反感
linkType设为 external 但 linkUrl 为相对路径跳转链接失效
htmlContent包含外部 script 引用加载失败或被浏览器安全策略阻止

内容禁忌类型

禁止配置的广告内容

1. 误导性广告 — 标题/图片与实际跳转内容不符，如"免费领取"实际跳转到付费页面。后果：用户投诉，品牌信誉受损。

2. 弹窗轰炸 — 弹窗广告不设频次限制，每次访问都弹出。后果：用户跳出率飙升，搜索引擎降权。

3. 超大素材 — 单张图片超过 1MB 或视频超过 20MB。后果：页面加载缓慢，Core Web Vitals 评分下降。

4. 过期广告未下线 — 活动结束后未设置 endAt 或未将 isActive 设为 false。后果：用户看到过期活动信息，产生困惑。

5. 恶意 HTML — htmlContent 中包含恶意脚本或钓鱼链接。后果：安全风险，法律后果。

最佳实践总结

广告内容是高频迭代的运营资产。每次创建广告时遵循"素材匹配区域尺寸、文案简洁有力、样式与品牌一致、定时频次合理"四项原则。活动结束后及时下线（isActive=false 或设置 endAt），保留历史记录供后续分析。定期检查区域下的内容列表，清理过期和无效内容，保持广告系统整洁。
