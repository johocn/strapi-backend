# 5. 积分兑换商品

> 返回 [首页](index.md)

### 5.1 进入积分商城

点击底部「积分兑换」Tab，进入积分商城：

- 顶部显示当前积分余额
- 可点击查看「积分明细」
- 商品卡片展示：图片、名称、所需积分、库存、配送方式、标签

### 5.2 商品类型

| 类型 | 说明 |
|------|------|
| 积分兑换 | 纯积分兑换，无需付款 |
| 到店购买 | 到店付款购买（不消耗积分） |
| 积分 + 现金 | 混合模式，消耗积分并支付部分现金 |

### 5.3 兑换流程

1. 点击商品卡片查看详情
2. 确认兑换信息（所需积分、数量、配送方式）
3. 选择配送方式：
   - **快递配送**：填写收件人姓名、电话、地址
   - **到店自提**：选择自提点、填写电话
4. 系统自动计算积分扣除顺序：
   - 优先扣除本渠道积分
   - 不足时勾选其他渠道积分
   - 仍不足时使用全局积分
5. 点击「确认兑换」
6. 兑换成功，显示取货码（自提）或等待发货（快递）

### 5.4 查看兑换记录

进入「我的 → 兑换记录」或从积分商城跳转：

- **状态筛选**：待处理 / 已审核 / 已发货 / 已完成 / 已取消
- **订单信息**：商品名称、消耗积分、数量、配送方式、自提点、快递单号、收件信息
- **自提订单**：点击可查看取货码二维码，到店出示
- **混合订单**：显示现金支付金额

### 5.5 自提点

兑换时选择自提配送后，需要选择自提点：

- **自提点列表**：显示名称、地址、距离、营业时间
- **快捷操作**：拨打电话 📞、导航 🧭
- **自提点详情**：可查看营业执照、完整地址、营业时间
