# 3. 课程浏览与学习

> 返回 [首页](index.md)

### 3.1 浏览课程列表

进入「全部课程」Tab，可以：

- **搜索**：顶部搜索框输入关键词
- **分类筛选**：横向滑动的分类标签
- **课程卡片**：展示封面、分类、难度、学习人数、付费/免费标签、积分标签

### 3.2 查看课程详情

点击课程卡片进入课程详情页，可看到：

- 课程封面、标题、简介
- 讲师信息
- 课时列表（含每个课时的学习进度）
- 已领积分标记（"积分已领"标签表示该课时答题积分已领取）
- 课程统计：总课时数、已完成课时数、已获积分状态

### 3.3 观看视频学习

点击课时进入视频学习页，核心功能：

#### 视频播放

- 自动从上次观看位置继续播放
- 支持暂停、快进、倍速（如设备支持）
- 横屏全屏播放

#### 进度自动保存

- 播放过程中每 10 秒自动保存进度
- 暂停、退出页面、切换后台时立即保存
- 观看进度 ≥ 98% 自动标记课时完成

#### 切换课时

- 右侧（或底部）课时列表可快速切换
- 每个课时显示进度百分比
- 已领积分的课时有专属标签

### 3.4 我的课程

进入「我的课程」Tab，查看个人学习情况：

- **顶部统计**：已学课程数、总积分、今日答题次数
- **正在学习**：未完成的课程，显示进度条
- **已完成课程**：已学完的课程列表
- 点击课程卡片可继续学习
