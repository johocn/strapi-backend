# 2. 账号登录与注册

> 返回 [首页](index.md)

### 2.1 游客模式

未登录状态下可浏览课程列表，但无法进入课程详情、学习视频、答题或兑换商品。点击被限制的功能会跳转到登录页。

### 2.2 登录方式

应用支持多种登录方式，具体可用方式由后台配置决定：

#### 方式 1：手机验证码登录

1. 在登录页输入手机号
2. 点击「获取验证码」，等待短信
3. 输入 6 位验证码
4. 点击「登录」
5. 未注册的手机号会**自动注册**并登录

#### 方式 2：账号密码登录

1. 切换到「密码登录」标签
2. 输入用户名或邮箱
3. 输入密码
4. 点击「登录」

#### 方式 3：微信登录（小程序）

- 在微信小程序中打开应用，自动静默登录（无需点击）
- 首次使用会请求获取用户信息授权
- 授权后自动登录并绑定微信账号

#### 方式 4：微信登录（H5 公众号）

- 在微信内打开 H5 网页，自动调起微信授权
- 默认使用 `snsapi_base` 静默登录（无感知）
- 如需获取用户详细信息，会切换到 `snsapi_userinfo` 授权

#### 方式 5：扫码登录（PC 端）

- 在 PC 浏览器中打开应用，显示二维码
- 使用微信扫码后即可登录

#### 方式 6：SSO 单点登录

- 如果应用接入了 SSO，访问时会自动跳转到 SSO 登录页
- 在 SSO 页面完成登录后自动回跳

### 2.3 注册账号

1. 在登录页点击「注册」
2. 输入用户名、邮箱、密码（≥ 6 位）
3. 确认密码
4. （可选）输入邀请码，注册后可建立推荐关系并获得奖励
5. 点击「注册」完成

### 2.4 忘记密码

1. 在登录页点击「忘记密码」
2. 输入注册邮箱
3. 系统发送密码重置链接到邮箱
4. 登录邮箱点击链接重置密码
