# 6. 个人中心与互动

> 返回 [首页](index.md)

### 6.1 进入个人中心

点击底部「我的」Tab：

- **游客模式**：显示登录/注册入口
- **已登录**：显示头像、昵称、用户 ID、积分余额

### 6.2 快捷功能

- **每日签到**：显示连续签到天数，点击签到
- **任务中心**：查看可完成的任务列表，按类型分组（日常 / 学习 / 互动 / 社交 / 一次性）
- **每日学习圈**：显示今日答题次数 / 3 上限

### 6.3 菜单功能

| 菜单 | 说明 |
|------|------|
| 我的课程 | 跳转到「我的课程」Tab |
| 全部课程 | 跳转到「全部课程」Tab |
| 积分商城 | 跳转到「积分兑换」Tab |
| 兑换记录 | 查看历史兑换订单 |
| 引导页 | 重新查看应用引导 |
| 设置 | 应用设置 |
| 关于 | 应用信息 |
| 退出登录 | 清除登录状态 |

### 6.4 积分明细

进入「我的 → 积分明细」：

- **统计卡片**：累计获得、累计消费、当前余额
- **筛选**：全部 / 收入 / 支出
- **明细列表**：每条记录显示动作名称、积分数、时间
