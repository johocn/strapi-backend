# 4. 答题与积分获取

> 返回 [首页](index.md)

### 4.1 答题入口

答题有两种方式：

#### 方式 1：视频完成后弹窗答题（推荐）

1. 观看视频至 98% 以上完成
2. 自动弹出答题窗口
3. 默认 2 道题
4. 答完后立即显示得分并可领取积分

#### 方式 2：独立答题页

1. 在课程详情页或视频页点击「去答题」
2. 进入独立答题界面
3. 完成答题后领取积分

### 4.2 题目类型

- **单选题**：选择一个正确答案
- **多选题**：选择所有正确答案
- **判断题**：判断对错

### 4.3 答题规则

| 规则 | 说明 |
|------|------|
| 题目数量 | 每次答题默认 2 道题 |
| 通过线 | 答对率 ≥ 60% 视为通过 |
| 每日上限 | 每天最多答题 3 次 |
| 重试 | 根据后台配置，可能允许重试（有次数限制） |
| 练习模式 | 已领积分的课时仍可答题，但不再发放积分 |

### 4.4 领取积分

答题通过后：

1. 显示结果卡片（答对率、获得积分）
2. 点击「领取积分」
3. 如果开启了**跨渠道积分**功能且您有多个渠道，会弹出渠道选择器
4. 选择要计入积分的渠道（默认先消耗本渠道，不足时可选其他渠道或全局积分）
5. 领取成功后积分即时到账

### 4.5 其他获取积分的方式

除答题外，还可通过以下方式获取积分：

- **每日签到**：每天签到得积分，连续签到有里程碑奖励（如 7 天、30 天）
- **任务中心**：完成日常任务、学习任务、互动任务等
- **邀请好友**：每邀请 1 位好友注册得 50 积分
