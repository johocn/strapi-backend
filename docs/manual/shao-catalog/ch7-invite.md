# 7. 邀请好友赚积分

> 返回 [首页](index.md)

### 7.1 我的邀请码

在「我的」页面找到「邀请好友」卡片：

- 显示专属邀请码（可复制）
- 显示已邀请人数、累计获得积分

### 7.2 分享方式

3 种分享方式：

1. **分享给微信好友**：发送给微信好友/群聊
2. **分享到朋友圈**：发布到朋友圈
3. **生成海报**：生成图片海报，可保存到相册或扫码识别

> 分享链接会自动带上您的邀请码，好友通过链接注册后自动建立推荐关系。

### 7.3 邀请奖励

- 每成功邀请 1 位好友注册，获得 **50 积分**
- 好友后续的消费/学习可能也会给您带来渠道分成（视具体配置）
