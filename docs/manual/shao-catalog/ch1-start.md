# 1. 快速开始

> 返回 [首页](index.md)

### 1.1 应用入口

本应用支持多种访问方式：

- **H5 网页版**：在浏览器中访问应用网址（如 `https://v.joho.cn`）
- **微信小程序**：在微信中搜索小程序名称打开
- **微信公众号**：在微信中关注公众号后通过菜单进入

### 1.2 首次使用

首次打开应用会显示引导页，分 4 步介绍核心玩法：

1. 浏览全部课程
2. 观看视频学习
3. 答题获取积分
4. 积分兑换商品

滑动至最后一页点击「开始使用」进入主页。

### 1.3 核心规则（务必了解）

| 规则 | 说明 |
|------|------|
| 每日答题上限 | 每天最多答题 **3 次**（不同课程分别计算） |
| 答题通过率 | 答对率 ≥ **60%** 视为通过，可领取积分 |
| 视频完成度 | 观看进度 ≥ **98%** 视为课时完成 |
| 邀请奖励 | 每成功邀请 1 位好友注册，获得 **50 积分** |
| 积分用途 | 兑换商城商品（实物 / 虚拟 / 自提） |
