# 3. 课程管理

> 返回 [首页](index.md)

### 3.1 课程列表

**入口**：课程中心 → 课程管理

#### 搜索与筛选

- **关键词搜索**：按课程名称模糊搜索
- **状态筛选**：全部 / 草稿 / 待审核 / 已发布 / 已下架
- **分类筛选**：按课程分类筛选

#### 课程卡片信息

每张课程卡片显示：
- 封面图 + 状态标签（草稿/已发布等）
- 课程名称、描述摘要
- 价格（免费 / ¥xx.xx）
- 学员数、课程时长
- 操作按钮：发布 / 下架 / 编辑 / 删除

#### 课程状态流转

```
草稿 (draft) → 已发布 (published) → 已下架 (unpublished)
                  ↑                     |
                  └───── 重新发布 ←──────┘
```

- **草稿**：新建未发布，前端不可见
- **已发布**：前端可见，学员可学习
- **已下架**：前端不可见，已授权学员仍可继续学习

### 3.2 新增/编辑课程

**入口**：课程列表 →「+ 新增课程」或「编辑」

#### 基本信息

| 字段 | 必填 | 说明 |
|------|------|------|
| 课程名称 | * | 课程标题 |
| 课程描述 | | 课程简介（前端列表展示摘要） |
| 作者 | | 讲师/作者名称 |

#### 媒体资源

| 字段 | 必填 | 说明 |
|------|------|------|
| 封面图 | | 课程列表展示用图，建议 16:9 |
| 缩略图 | | 课程卡片小图，可复用封面图 |

#### 价格设置

| 字段 | 说明 |
|------|------|
| 免费课程 | 开启后前端显示「免费」标签 |
| 付费课程 | 开启后需设置价格 |
| 现价（分） | 实际售价，单位分（如 9900 = ¥99.00） |
| 原价（分） | 划线价，用于显示优惠 |
| 折扣价（分） | 特价活动价 |

> **注意**：价格单位是「分」，100 = ¥1.00，避免浮点精度问题。

#### 分类标签

- **课程分类**：单选，从分类树中选择
- **课程标签**：多选，可添加多个标签

#### 知识点关联

- **关联知识点**：多选，从知识点库中选择，用于推荐与关联学习

#### 学习设置

| 字段 | 说明 |
|------|------|
| 难度级别 | 入门 / 初级 / 中级 / 高级 / 专家 |
| 课程等级 | L1 ~ L5（自定义等级体系） |
| 课程时长（分钟） | 用于列表展示，不强制校验实际视频时长 |
| 排序 | 数字越小越靠前 |

#### 渠道设置

| 字段 | 说明 |
|------|------|
| 渠道范围 | 全部渠道（跨渠道公开）/ 指定渠道 |
| 指定渠道 | 当渠道范围为"指定渠道"时，勾选可见的渠道 |

> **跨渠道公开**：所有租户的学员都能看到此课程；**指定渠道**：仅勾选的渠道可见。

### 3.3 课程详情页

点击课程卡片进入详情页，可查看：
- 课程基本信息
- 课时列表（点击进入课时管理）
- 学员授权情况
- 学习统计数据

### 3.4 发布与下架

- **发布**：状态从草稿/下架变为已发布，前端立即可见
- **下架**：状态变为已下架，前端不可见，已授权学员仍可继续学习
