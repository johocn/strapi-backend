# 5. 用户课程授权

> 返回 [首页](index.md)

### 5.1 授权列表

**入口**：课程中心 → 用户授权

#### 搜索与筛选

- **关键词搜索**：按用户名或课程名称搜索
- **授权类型筛选**：全部 / 手动授权 / 自动授权 / 购买授权 / 邀请奖励

#### 授权记录信息

- 用户名、课程名称
- 授权类型（手动/自动/购买/邀请）
- 到期时间（如有）
- 状态（有效/已过期）

### 5.2 手动授权

**入口**：授权列表 →「+ 授权」

1. 选择用户（支持搜索用户名/邮箱）
2. 选择课程
3. 选择授权类型（手动）
4. 设置到期时间（可选，不填为永久）
5. 点击「确认授权」

### 5.3 撤销授权

- 在授权列表点击「撤销」
- 撤销后学员无法继续学习该课程
- 已产生的学习进度和积分记录保留
