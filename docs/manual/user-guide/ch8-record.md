# 8. 答题记录与评分

> 返回 [首页](index.md)

### 8.1 答题记录列表

**入口**：题库系统 → 答题记录

#### 搜索与筛选

- **关键词搜索**：按用户名或题目内容搜索
- **状态筛选**：全部 / 待评分 / 已评分

#### 记录信息

- 题目/考试名称
- 用户名
- 得分
- 状态（待评分 / 已评分）

### 8.2 人工评分

**适用场景**：简答题、填空题等无法自动判分的题型

**操作步骤**：

1. 在答题记录列表找到「待评分」记录
2. 点击「评分」按钮
3. 查看学员作答内容
4. 参考标准答案，给出分数
5. 点击「提交评分」

### 8.3 查看答题详情

点击「详情」可查看：
- 学员作答的每道题
- 正确答案对比
- 得分明细
- 答题时间
