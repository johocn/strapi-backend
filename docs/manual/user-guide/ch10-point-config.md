# 10. 积分全局配置

> 返回 [首页](index.md)

### 10.1 入口

**积分体系 → 积分配置**

### 10.2 基础设置

| 字段 | 说明 |
|------|------|
| 启用积分系统 | 总开关，关闭后所有积分功能不可用 |
| 兑换比率（1积分 = ? 元） | 积分与现金的换算比率，如 0.01 表示 100 积分 = ¥1 |
| 启用兑换功能 | 开启后学员可兑换商品 |
| 启用任务中心 | 开启后学员可见任务中心 |

### 10.3 过期设置

| 字段 | 说明 |
|------|------|
| 启用积分过期 | 开启后积分按规则过期 |
| 过期天数 | 获取后多少天过期（0 = 永不过期） |
| 过期提醒天数 | 过期前多少天提醒学员 |
| 每日获取上限 | 每天最多获取的积分数（0=不限） |

### 10.4 签到设置

| 字段 | 说明 |
|------|------|
| 启用每日签到 | 开启后学员可每日签到 |
| 启用连续签到阶梯奖励 | 开启后连续签到有里程碑奖励 |
| 阶梯里程碑 | 如 `7,30,90` 表示连续 7 天、30 天、90 天有额外奖励 |

> 签到固定积分在「积分规则」中 `daily_sign_in` 规则配置，阶梯奖励在「积分类型」中配置。
