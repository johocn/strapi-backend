# 11. 学习数据监控

> 返回 [首页](index.md)

### 11.1 课程学习进度

**入口**：学习数据 → 课程学习进度

#### 搜索与筛选

- 按用户名或课程名称搜索
- 按状态筛选：全部 / 学习中 / 已完成

#### 数据展示

每条记录显示：
- 用户名、课程名称
- 进度条（百分比）
- 已完成课时 / 总课时
- 状态（学习中 / 已完成）
- 已获积分
- 最后学习时间

### 11.2 课时学习进度

**入口**：学习数据 → 课时学习进度

更细粒度的课时级别进度，显示：
- 用户名、课时名称
- 观看进度百分比
- 观看时长
- 是否完成
- 最后观看位置（可恢复播放）

### 11.3 数据应用场景

- **学员流失分析**：进度长期停滞的学员可主动跟进
- **课程优化**：完成率低的课时可能内容过长或难度过高
- **积分发放核查**：对比学习进度与积分记录，发现异常
