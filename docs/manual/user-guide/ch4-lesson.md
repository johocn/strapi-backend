# 4. 课时管理

> 返回 [首页](index.md)

### 4.1 课时列表

**入口**：课程详情 → 课时列表，或独立入口

#### 课时卡片信息

- 课时名称、类型（视频/图文/音频）
- 时长、排序
- 学习进度统计
- 操作：编辑 / 删除

### 4.2 新增/编辑课时

**入口**：课时列表 →「+ 新增课时」或「编辑」

#### 基本信息

| 字段 | 必填 | 说明 |
|------|------|------|
| 课时名称 | * | 课时标题 |
| 所属课程 | * | 选择关联的课程 |
| 课时类型 | * | 视频 / 音频 / 图文 |
| 课时概述 | | 简短介绍 |
| 课时内容 | | 图文类型的正文内容 |

#### 媒体资源

| 字段 | 必填 | 说明 |
|------|------|------|
| 缩略图 | | 课时封面 |
| 视频（视频类型） | | 视频 URL，可从媒体库选择 |
| 音频（音频类型） | | 音频 URL |
| 附件 | | PDF、文档等附件 |

> **视频上传**：建议先在「媒体管理」上传视频，复制 URL 后填入；或直接填写外部视频 URL（需支持跨域播放）。

#### 答题积分设置

| 字段 | 说明 |
|------|------|
| 启用积分 | 开启后学员答题通过可领取积分 |
| 积分类型 | quiz_points（答题积分）/ lesson_points（课时积分） |
| 积分数值 | 答题通过后发放的积分数 |
| 答题次数上限 | 每日该课时可答题次数（默认 3） |
| 通过线 | 答对率阈值（默认 60%） |

#### 其他设置

| 字段 | 说明 |
|------|------|
| 时长（分钟） | 课时时长，用于展示 |
| 排序 | 课时在课程内的顺序 |
| 是否免费试看 | 开启后未授权学员可观看 |

### 4.3 课时类型说明

| 类型 | 适用场景 | 学员端体验 |
|------|----------|-----------|
| 视频 | 主流场景 | 视频播放器，自动记录进度 |
| 图文 | 文字教程 | 渲染 markdown 内容，阅读完成即视为学完 |
| 音频 | 音频课程 | 音频播放器，类似视频进度记录 |
