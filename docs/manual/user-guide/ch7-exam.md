# 7. 考试管理

> 返回 [首页](index.md)

### 7.1 考试列表

**入口**：题库系统 → 考试管理

显示所有考试列表，含考试标题、状态、题目数量、参与人数等。

### 7.2 新增/编辑考试

| 字段 | 必填 | 说明 |
|------|------|------|
| 考试标题 | * | 考试名称 |
| 考试描述 | | 考试说明 |
| 时间限制（分钟） | | 不填为不限时 |
| 及格分数 | | 达到该分数视为通过 |
| 状态 | * | 草稿 / 已发布 |

### 7.3 考试与题库的关系

- 考试是从题库中**抽取题目**组成的试卷
- 可按知识点、难度、题型配置抽题规则
- 学员参加考试时系统按规则随机抽题
