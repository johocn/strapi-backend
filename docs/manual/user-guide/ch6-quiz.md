# 6. 题库管理

> 返回 [首页](index.md)

### 6.1 题目列表

**入口**：题库系统 → 题库管理

#### 搜索与筛选

- **关键词搜索**：按题目内容模糊搜索
- **题型筛选**：全部 / 单选 / 多选 / 判断 / 填空 / 简答
- **难度筛选**：全部 / 简单 / 中等 / 困难

#### 题目卡片信息

- 题型标签（彩色）
- 题目内容
- 难度、分值
- 状态（已发布 / 草稿）
- 操作：编辑 / 删除

### 6.2 新增/编辑题目

**入口**：题库列表 →「+ 新增题目」或「编辑」

#### 基本信息

| 字段 | 必填 | 说明 |
|------|------|------|
| 题目类型 | * | 单选 / 多选 / 判断 / 填空 / 简答 |
| 题目内容 | * | 题干文本 |
| 题目解析 | | 答题后展示的解析说明 |

#### 关联设置（非必填）

| 字段 | 说明 |
|------|------|
| 关联课程 | 题目所属课程（用于课程答题） |
| 关联课时 | 题目所属课时（视频完成后弹窗答题用） |
| 关联知识点 | 多选知识点，用于推荐与统计 |

> **重要**：视频完成后弹窗答题的题目必须关联到具体课时，系统从该课时关联的题目中随机抽取。

#### 选项设置（选择题）

- **单选题**：添加多个选项（A/B/C/D...），选择 1 个正确答案
- **多选题**：添加多个选项，勾选所有正确答案
- 支持动态添加/删除选项

#### 答案设置

| 题型 | 答案形式 |
|------|----------|
| 单选题 | 选择 1 个选项字母（A/B/C/D） |
| 多选题 | 勾选多个选项字母 |
| 判断题 | 选择「正确」或「错误」 |
| 填空题 | 输入参考答案 |
| 简答题 | 输入参考回答（需人工评分） |

#### 属性设置

| 字段 | 说明 |
|------|------|
| 难度 | 简单 / 中等 / 困难 |
| 分值 | 题目分值（用于考试计分） |
| 是否发布 | 发布后才会被系统抽取 |

### 6.3 批量导入题目

**入口**：题库管理 →「批量导入」

#### 操作步骤

1. **下载模板**：点击「下载导入模板」，获取 Excel/CSV 模板
2. **填写题目**：按模板格式填写题目，必填字段：题型、题目内容、正确答案
3. **上传文件**：点击上传区域选择文件（支持 .xlsx / .xls / .csv）
4. **开始导入**：点击「开始导入」按钮
5. **查看结果**：导入完成后显示成功/失败数量，失败项会列出具体行号和错误原因

#### 模板字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 题型 | * | 单选/多选/判断/填空/简答 |
| 题目内容 | * | 题干 |
| 选项A | 选择题必填 | 选项 A 内容 |
| 选项B | 选择题必填 | 选项 B 内容 |
| 选项C | | 选项 C 内容 |
| 选项D | | 选项 D 内容 |
| 正确答案 | * | 单选填字母（如 A），多选填字母逗号分隔（如 A,C），判断填 正确/错误 |
| 难度 | | 简单/中等/困难 |
| 分值 | | 数字 |
| 解析 | | 题目解析 |
| 关联课程 | | 课程名称 |
| 关联课时 | | 课时名称 |
