# 9. 积分规则配置

> 返回 [首页](index.md)

### 9.1 积分规则列表

**入口**：积分体系 → 积分规则

#### 筛选

- **任务分组**：日常 / 学习 / 互动 / 社交 / 一次性 / 其他
- **仅启用**：开关，过滤已禁用的规则

#### 规则卡片信息

- 动作标识（action）
- 状态（启用/禁用）
- 分类（增加/扣除）
- 积分数
- 每日上限 / 一次性标识

### 9.2 新增/编辑积分规则

**入口**：积分规则列表 →「+ 新增」或「编辑」

| 字段 | 必填 | 说明 |
|------|------|------|
| 动作标识 (action) | * | 唯一标识，如 `daily_sign_in`、`quiz_pass`、`lesson_complete`（编辑时不可改） |
| 分类 | * | 增加 / 扣除 |
| 任务分组 | | 日常 / 学习 / 互动 / 社交 / 一次性 / 其他 |
| 积分数 | * | 该动作发放/扣除的积分数 |
| 每日上限 | | 每天最多触发次数（0=不限） |
| 一次性 | | 是否只能触发 1 次 |
| 描述 | | 规则说明 |

### 9.3 常用动作标识

| action | 含义 | 建议 |
|--------|------|------|
| `daily_sign_in` | 每日签到 | 增加，每日 1 次 |
| `quiz_pass` | 答题通过 | 增加，关联课时积分 |
| `lesson_complete` | 课时完成 | 增加，可选 |
| `course_complete` | 课程完成 | 增加，一次性 |
| `invite_register` | 邀请注册 | 增加，一次性/每日上限 |
| `redeem_product` | 兑换商品 | 扣除 |
| `manual_adjust` | 手动调整 | 增加/扣除 |

### 9.4 启用/禁用规则

- 在规则列表点击「启用」/「禁用」
- 禁用后该动作不再触发积分变化
- 已发放的积分不回滚
