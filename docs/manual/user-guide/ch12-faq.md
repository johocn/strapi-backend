# 12. 常见问题

> 返回 [首页](index.md)

### 12.1 课程相关

#### Q：课程发布了，学员看不到？

A：检查以下几点：
1. 课程状态是否为「已发布」
2. 渠道设置：当前学员所在渠道是否在可见范围内
3. 学员是否已被授权（付费课程需授权或购买）
4. 多租户环境下，站点配置是否正确

#### Q：课程价格单位是什么？

A：单位是「分」，100 = ¥1.00。例如设置 9900 表示 ¥99.00。

#### Q：删除课程后学员的学习进度会丢失吗？

A：会。删除课程会级联删除相关课时、学习进度、答题记录。建议使用「下架」代替删除。

### 12.2 课时相关

#### Q：视频为什么播放不了？

A：检查以下几点：
1. 视频 URL 是否可访问（跨域问题）
2. 视频格式是否支持（建议 MP4/H.264）
3. 建议先在「媒体管理」上传视频，复制 URL 填入

#### Q：学员答题后没领到积分？

A：检查以下几点：
1. 课时「答题积分设置」是否启用
2. 课时关联的题目是否已发布
3. 「积分规则」中 `quiz_pass` 规则是否启用
4. 学员当日答题次数是否已达上限
5. 学员是否已领过该课时积分（每课时只能领 1 次）

### 12.3 题库相关

#### Q：视频完成后为什么没有弹窗答题？

A：检查以下几点：
1. 课时是否关联了已发布的题目
2. 课时类型是否为「视频」
3. 课时「答题积分设置」是否启用
4. 学员当日答题次数是否已达上限（默认 3 次）

#### Q：批量导入失败怎么办？

A：
1. 查看导入结果中的错误行号和原因
2. 常见错误：题型拼写错误、必填字段为空、答案格式不对
3. 修正后重新导入，已导入的题目不会重复

### 12.4 积分相关

#### Q：修改积分规则后，已发放的积分受影响吗？

A：不受影响。积分规则修改只影响后续触发的积分发放，已发放的积分不变。

#### Q：如何手动调整学员积分？

A：在「积分记录」页面，部分权限角色可使用「手动调整」功能，选择学员、输入调整积分数（正数增加/负数扣除）和原因。

#### Q：积分过期后学员会收到通知吗？

A：如启用过期提醒，系统会在过期前指定天数提醒学员。具体通知方式取决于通知配置。

### 12.5 授权相关

#### Q：授权到期后学员还能学习吗？

A：不能。授权到期后学员无法继续访问课程内容，但已产生的学习进度和积分记录保留。续期授权后可继续学习。

#### Q：如何批量授权？

A：目前仅支持单条授权。如需批量授权大量用户，建议联系开发人员通过后台 API 批量处理。
