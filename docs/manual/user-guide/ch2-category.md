# 2. 课程分类与标签

> 返回 [首页](index.md)

### 2.1 课程分类管理

**入口**：课程中心 → 课程管理 → 顶部「分类」按钮

#### 新增分类

1. 点击「+ 新增分类」
2. 填写分类名称
3. 选择父分类（可选，支持多级分类树）
4. 设置排序（数字越小越靠前）
5. 点击「保存」

#### 管理分类

- **编辑**：修改分类名称、父级、排序
- **删除**：分类下有课程时无法删除，需先迁移课程
- **排序**：通过 sort 字段控制显示顺序

### 2.2 课程标签管理

**入口**：课程中心 → 课程管理 → 顶部「标签」按钮

#### 新增标签

1. 点击「+ 新增标签」
2. 填写标签名称
3. 选择标签分组（如"难度"、"人群"、"方向"等）
4. 设置颜色（可选，用于前端展示）
5. 点击「保存」

#### 标签 vs 分类

| 维度 | 分类 | 标签 |
|------|------|------|
| 结构 | 树形层级 | 扁平 + 分组 |
| 数量 | 每个课程只能归属 1 个分类 | 每个课程可打多个标签 |
| 用途 | 主分类导航 | 多维度筛选、推荐 |
