## 13. 常见问题

### 13.1 登录失败

**问题**：输入用户名和密码后无法登录

**排查步骤**：

1. 检查用户名和密码是否正确
2. 检查网络连接是否正常
3. 检查服务器是否正常运行
4. 联系系统管理员重置密码

### 13.2 页面空白

**问题**：登录后页面显示空白

**排查步骤**：

1. 刷新页面
2. 清除浏览器缓存
3. 检查浏览器版本是否符合要求
4. 检查控制台是否有错误信息

### 13.3 权限不足

**问题**：无法访问某些菜单或执行某些操作

**排查步骤**：

1. 检查当前用户角色
2. 联系管理员获取更高权限
3. 确认是否需要先完成其他操作

### 13.4 文件上传失败

**问题**：上传图片或文件失败

**排查步骤**：

1. 检查文件大小是否超过限制
2. 检查文件格式是否支持
3. 检查网络连接是否正常
4. 联系管理员检查服务器存储配置

### 13.5 数据不显示

**问题**：页面不显示数据

**排查步骤**：

1. 检查筛选条件是否正确
2. 检查是否有权限查看该数据
3. 检查网络连接是否正常
4. 检查服务器是否正常运行

### 13.6 租户保存失败

**问题**：创建或编辑租户时保存失败

**排查步骤**：

1. 检查租户名称和域名是否填写
2. 检查是否选择了至少一个渠道
3. 检查表单中的必填项是否都已填写
4. 检查网络连接是否正常

### 13.7 课程发布后不可见

**问题**：课程发布后在前端不可见

**排查步骤**：

1. 检查课程状态是否为「已发布」
2. 检查课程的渠道范围设置是否正确
3. 检查是否设置了正确的积分归属渠道
4. 检查课程的时间设置是否在有效期内

### 13.8 渠道无法删除

**问题**：尝试删除渠道时失败

**排查步骤**：

1. 检查渠道下是否有子渠道，先删除子渠道
2. 检查渠道下是否有成员，先移除成员
3. 检查渠道是否被课程或其他资源引用
