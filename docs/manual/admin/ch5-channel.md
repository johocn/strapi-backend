## 5. 渠道管理

### 5.1 功能概述

渠道管理用于管理系统的渠道层级结构，支持多级渠道、成员管理和邀请码机制。

### 5.2 渠道层级

```
平台根渠道
├── 省级渠道
│   ├── 市级渠道
│   │   └── 个人渠道
│   └── 市级渠道
└── 省级渠道
    └── ...
```

**渠道层级说明：**

| 层级代码 | 显示名称 | 说明 |
|----------|----------|------|
| root | 根渠道 | 平台级渠道 |
| national | 全国 | 国家级渠道 |
| provincial | 省级 | 省级渠道 |
| city | 城市 | 市级渠道 |
| county | 区县 | 区县级渠道 |
| local | 本地 | 本地渠道 |
| store | 门店 | 门店级渠道 |
| core | 核心渠道 | 核心合作渠道 |
| senior | 高级渠道 | 高级渠道 |
| global | 全球渠道 | 全球渠道 |
| authorized | 授权渠道 | 授权渠道 |
| official | 官方渠道 | 官方渠道 |
| partner | 合作伙伴 | 合作伙伴渠道 |
| agent | 代理渠道 | 代理商渠道 |

### 5.3 创建渠道

**操作步骤**：

1. 点击左侧菜单「渠道管理」→「渠道列表」
2. 点击「+ 新增」按钮或右下角的「+」悬浮按钮
3. 填写渠道信息：

**渠道信息字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 渠道名称 | * | 渠道的显示名称 |
| 代码 | | 渠道的唯一代码（系统自动生成） |
| 描述 | | 渠道的描述信息 |
| 层级 | * | 选择渠道层级（root/national/provincial/city等） |
| 父渠道 | | 选择上级渠道（可选，创建子渠道时必填） |

4. 点击「保存」按钮

### 5.4 查看渠道列表

**操作步骤**：

1. 点击左侧菜单「渠道管理」→「渠道列表」
2. 在列表中查看所有渠道信息

**列表字段说明：**

| 字段名称 | 说明 |
|----------|------|
| 渠道名称 | 渠道的显示名称 |
| 代码 | 渠道的唯一代码 |
| 描述 | 渠道的描述信息 |
| 状态 | 启用/禁用 |
| 层级 | 渠道层级 |
| 上级 | 上级渠道名称 |

**筛选功能：**

| 筛选条件 | 说明 |
|----------|------|
| 搜索框 | 按渠道名称搜索 |
| 层级筛选 | 按渠道层级筛选 |
| 状态筛选 | 按启用/禁用状态筛选 |

### 5.5 查看渠道网络

**操作步骤**：

1. 在渠道列表页面点击顶部的「网络」按钮
2. 在弹出的窗口中查看渠道树结构
3. 可以展开/折叠各级渠道查看完整层级

### 5.6 管理渠道成员

**操作步骤**：

1. 在渠道列表中找到要管理的渠道
2. 点击「成员」按钮
3. 查看成员列表
4. 点击「邀请成员」添加新成员
5. 点击「移除成员」删除成员

### 5.7 编辑渠道

**操作步骤**：

1. 在渠道列表中找到要编辑的渠道
2. 点击「编辑」按钮
3. 修改渠道信息
4. 点击「保存」按钮

### 5.8 删除渠道

**操作步骤**：

1. 在渠道列表中找到要删除的渠道
2. 点击「删除」按钮
3. 在确认对话框中点击「确定」

> **注意**：删除渠道会级联删除所有子渠道和成员，此操作不可恢复，请谨慎操作。

### 5.9 生成邀请码

**操作步骤**：

1. 进入渠道详情页
2. 在「邀请码」区域点击「生成邀请码」
3. 复制邀请码分享给他人

### 5.10 常见问题与错误提示

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 无法创建子渠道 | 未选择父渠道 | 在创建渠道时选择父渠道 |
| 删除渠道失败 | 渠道下有子渠道或成员 | 先删除子渠道和成员，再删除当前渠道 |
| 搜索不到渠道 | 关键词输入错误 | 检查搜索关键词是否正确 |
