## 8. 题库管理

### 8.1 功能概述

题库管理用于管理系统中的题目，支持多种题型和难度级别。

### 8.2 创建题目

**操作步骤**：

1. 点击左侧菜单「题库管理」→「题目列表」
2. 点击「新建题目」按钮
3. 填写题目信息：

**题目信息字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 题目内容 | * | 题目的文本内容 |
| 题目类型 | * | single-choice（单选）/ multiple-choice（多选）/ true-false（判断）/ fill-blank（填空）/ essay（问答） |
| 难度等级 | | easy（简单）/ medium（中等）/ hard（困难） |
| 分数 | | 题目分值 |
| 正确答案 | * | 题目正确答案 |
| 选项 | | 选择题需要填写选项 |
| 解释说明 | | 题目解析（可选） |

4. 点击「保存」按钮

### 8.3 批量导入题目

**操作步骤**：

1. 点击左侧菜单「题库管理」→「批量导入」
2. 下载导入模板
3. 按照模板格式填写题目数据
4. 上传填写好的文件
5. 点击「导入」按钮

### 8.4 考试管理

**操作步骤**：

1. 点击左侧菜单「题库管理」→「考试管理」
2. 点击「新建考试」按钮
3. 填写考试信息：

**考试信息字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 考试名称 | * | 考试的显示名称 |
| 描述 | | 考试说明 |
| 题目来源 | | 从题库中选择题目 |
| 时间限制 | | 考试时长（分钟） |
| 及格分数 | | 及格线分数 |

4. 点击「保存」按钮

### 8.5 查看答题记录

**操作步骤**：

1. 点击左侧菜单「题库管理」→「答题记录」
2. 选择要查看的记录
3. 查看答题详情和得分
