## 6. 课程管理

### 6.1 功能概述

课程管理用于管理系统中的课程内容，包括课程、课时、分类、标签和知识点。支持：
- 创建/编辑/删除课程
- 配置课程基本信息
- 设置课程价格（免费/付费/折扣）
- 关联课程分类和标签
- 关联知识点
- 设置渠道权限范围
- 配置积分奖励
- 设置课程时间和状态

### 6.2 创建课程

**操作步骤**：

1. 返回首页面板，在「📚 课程中心」分区点击「课程管理」
2. 点击「+ 新增课程」按钮
3. 填写课程基本信息：

**基本信息字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 课程名称 | * | 课程的显示名称 |
| 课程描述 | | 课程的详细描述 |
| 作者 | | 课程作者名称 |

4. 上传媒体资源：

**媒体资源字段说明：**

| 字段名称 | 必填 | 说明 | 建议尺寸 |
|----------|------|------|----------|
| 封面图 | | 课程封面图片 | 800x600px |
| 缩略图 | | 课程缩略图 | 200x200px |

**上传操作步骤：**
- 点击上传区域
- 在弹出的媒体选择器中选择图片
- 图片会自动上传并显示预览

5. 设置课程价格：

**价格设置字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 免费课程 | | 开启后课程免费 |
| 付费课程 | | 开启后课程收费 |
| 现价（分） | | 当前售价，单位为分 |
| 原价（分） | | 原价，单位为分 |
| 折扣价（分） | | 折扣价，单位为分 |

> **注意**：价格单位为分，如100分 = 1元

6. 设置分类和标签：

**分类标签字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 课程分类 | | 选择课程所属分类 |
| 课程标签 | | 添加课程标签（可多选） |

**操作步骤：**
- 点击「课程分类」选择器，选择分类
- 点击「+ 添加标签」，在弹出的标签选择器中选择标签
- 点击标签右侧的「×」按钮移除标签

7. 关联知识点：

**操作步骤：**
- 点击「+ 添加知识点」
- 在弹出的知识点选择器中选择知识点（可多选）
- 点击知识点右侧的「×」按钮移除知识点

> **说明**：知识点是系统中预定义的知识体系节点，用于课程内容的结构化管理

8. 设置学习参数：

**学习设置字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 难度级别 | | beginner（初级）/ intermediate（中级）/ advanced（高级）/ expert（专家） |
| 课程等级 | | introductory（入门）/ foundation（基础）/ advanced（进阶）/ professional（专业） |
| 课程时长（分钟） | | 课程总时长 |
| 排序 | | 课程在列表中的排序优先级，数值越小越靠前 |

9. 设置渠道范围：

**渠道设置字段说明：**

| 设置项 | 说明 |
|--------|------|
| 全部渠道 | 课程对所有渠道公开，跨渠道可见 |
| 指定渠道 | 课程仅对指定渠道的成员可见，渠道专属课程 |
| 积分归属渠道 | 指定渠道模式下，学习本课程获得的积分归属此渠道 |
| 允许跨渠道访问 | 关闭后，游客无法浏览此课程 |

**操作步骤（指定渠道模式）：**
- 选择「指定渠道」选项
- 点击「点击选择渠道」，在弹出的渠道选择器中选择渠道（可多选）
- 点击「点击选择积分归属渠道」，在已选渠道中选择积分归属渠道（单选）

> **注意**：指定渠道模式下，积分归属渠道必须在所属渠道中选择

10. 设置积分奖励（如果积分系统已启用）：

**积分设置字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 启用积分 | | 是否启用课程积分奖励 |
| 积分数量 | | 完成课程可获得的积分数量 |
| 积分类型 | | course_points（课程积分）/ lesson_points（课时积分） |

11. 设置时间信息：

**时间设置字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 报名开始日期 | | 课程报名开始时间 |
| 报名结束日期 | | 课程报名结束时间 |
| 课程开始日期 | | 课程正式开始时间 |
| 课程结束日期 | | 课程结束时间 |

12. 设置课程状态：

**状态管理字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 课程状态 | | draft（草稿）/ pending（待审核）/ published（已发布）/ archived（已归档） |
| 审核状态 | | pending（待审核）/ approved（已通过）/ rejected（已拒绝） |
| 精选课程 | | 是否设为精选课程，精选课程会在首页优先展示 |

13. 点击「保存课程」按钮

### 6.3 编辑课程

**操作步骤**：

1. 在课程列表中点击要编辑的课程名称
2. 修改课程信息（参考创建课程的字段说明）
3. 点击「保存课程」按钮

### 6.4 删除课程

**操作步骤**：

1. 在课程列表中找到要删除的课程
2. 点击「删除」按钮
3. 在确认对话框中点击「确定」

### 6.5 添加课时

**操作步骤**：

1. 进入课程详情页
2. 点击「添加课时」按钮
3. 填写课时信息：

**课时信息字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 课时标题 | * | 课时的显示名称 |
| 类型 | * | video（视频）/ audio（音频）/ article（文章）/ quiz（测验） |
| 内容链接 | | 视频或音频链接 |
| 描述 | | 课时简介 |
| 排序 | | 课时在课程中的顺序 |

4. 点击「保存」按钮

### 6.6 课程分类管理

**操作步骤**：

1. 返回首页面板，在「📚 课程中心」分区点击「课程分类」
2. 点击「新建分类」按钮
3. 填写分类名称和描述
4. 点击「保存」按钮

### 6.7 课程标签管理

**操作步骤**：

1. 返回首页面板，在「🏷️ 标签体系」分区点击「标签管理」
2. 点击「新建标签」按钮
3. 填写标签名称
4. 点击「保存」按钮

### 6.8 知识点管理

**操作步骤**：

1. 返回首页面板，在「🏷️ 标签体系」分区点击「知识点」
2. 点击「新建知识点」按钮
3. 填写知识点名称和描述
4. 选择所属学科
5. 设置难度级别
6. 点击「保存」按钮

### 6.9 常见问题与错误提示

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 提示"请输入课程名称" | 课程名称未填写 | 填写课程名称 |
| 提示"指定渠道模式下，请至少选择1个所属渠道" | 指定渠道模式下未选择渠道 | 在渠道设置中选择至少一个渠道 |
| 提示"请选择积分归属渠道" | 指定渠道模式下未选择积分归属渠道 | 选择积分归属渠道 |
| 提示"积分归属渠道必须在所属渠道中" | 积分归属渠道不在已选渠道中 | 重新选择积分归属渠道，必须从已选渠道中选择 |
| 课程发布后不可见 | 课程状态为草稿或待审核 | 将课程状态改为已发布 |
