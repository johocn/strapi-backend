## 10. 系统管理

### 10.1 功能概述

系统管理用于管理系统的用户、角色和权限配置。

### 10.2 用户管理

**操作步骤**：

1. 点击左侧菜单「系统管理」→「用户管理」
2. 查看用户列表
3. 点击「编辑」修改用户信息
4. 点击「删除」删除用户
5. 点击「重置密码」重置用户密码

### 10.3 角色管理

**操作步骤**：

1. 点击左侧菜单「系统管理」→「角色管理」
2. 查看角色列表
3. 点击「编辑」修改角色权限
4. 点击「新建角色」创建新角色
5. 设置角色权限：
   - 选择要授予的权限
   - 保存角色配置

### 10.4 权限管理

**操作步骤**：

1. 点击左侧菜单「系统管理」→「权限管理」
2. 查看所有权限列表
3. 搜索权限
4. 查看权限详情

### 10.5 用户角色分配

**操作步骤**：

1. 点击左侧菜单「系统管理」→「用户角色」
2. 选择用户
3. 为用户分配角色
4. 保存配置
