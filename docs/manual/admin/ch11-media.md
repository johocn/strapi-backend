## 11. 媒体管理

### 11.1 功能概述

媒体管理用于管理系统中的图片和文件资源。

### 11.2 上传文件

**操作步骤**：

1. 点击左侧菜单「媒体管理」→「媒体库」
2. 点击「上传文件」按钮
3. 选择要上传的文件
4. 等待上传完成
5. 文件会自动保存到媒体库中

### 11.3 管理文件

**操作步骤**：

1. 在媒体库中找到要管理的文件
2. 点击「预览」查看文件
3. 点击「编辑」修改文件信息
4. 点击「删除」删除文件

### 11.4 使用文件

在编辑课程、租户等内容时，可以从媒体库中选择已上传的文件作为封面图片或其他用途。
