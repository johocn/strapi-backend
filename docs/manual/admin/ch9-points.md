## 9. 积分管理

### 9.1 功能概述

积分管理用于管理系统的积分体系，包括积分类型、规则、记录和兑换。

### 9.2 积分类型管理

**操作步骤**：

1. 返回首页面板，在「💎 积分体系」分区点击「积分类型」
2. 点击「新建积分类型」按钮
3. 填写积分类型信息：

**积分类型字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 类型代码 | * | 唯一标识，如 "study_points" |
| 类型名称 | * | 显示名称，如 "学习积分" |
| 描述 | | 类型说明 |
| 是否启用 | | 默认启用 |
| 是否可过期 | | 默认启用 |
| 过期天数 | | 默认 365 天 |

4. 点击「保存」按钮

### 9.3 积分规则管理

**操作步骤**：

1. 返回首页面板，在「💎 积分体系」分区点击「积分规则」
2. 点击「新建规则」按钮
3. 填写规则信息：

**规则信息字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 积分类型 | | 选择积分类型 |
| 积分数 | | 奖励积分数量 |
| 条件 | | 触发条件（可选） |
| 限制 | | 使用限制（可选） |
| 有效期 | | 规则生效时间（可选） |

4. 点击「保存」按钮

### 9.4 积分记录查看

**操作步骤**：

1. 返回首页面板，在「💎 积分体系」分区点击「积分记录」
2. 使用筛选条件查找记录：
   - 用户ID
   - 积分类型
   - 时间范围
3. 查看积分变更记录

### 9.5 积分兑换管理

**操作步骤**：

1. 返回首页面板，在「💎 积分体系」分区点击「兑换记录」
2. 点击「新建兑换商品」按钮
3. 填写商品信息：

**商品信息字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 商品名称 | * | 兑换商品名称 |
| 描述 | | 商品说明 |
| 所需积分 | * | 兑换所需积分 |
| 库存 | | 商品数量 |

4. 点击「保存」按钮

### 9.6 积分统计

**操作步骤**：

1. 返回首页面板，在「💎 积分体系」分区点击「积分统计」
2. 查看积分发放、消费和余额统计
3. 使用时间筛选器查看不同时间段的数据
